# A股投资体系 v4.0

> **合并自**: v1.0 执行手册（架构） + v2.0 研究助手（数据） + v3.0 纪律执行器（审问）
> **六层**: 宏观 → 赛道 → 排雷 → 理解 → 择时 → 执行
> **原则**: 每层只做一件事。不堆规则。不重复淘汰。
> **角色分工**:
>   Hermes → 定时拉数据（W&W、宏观、K线扫描）
>   Claude Code → 交互式走六层流程 + 审问你
>   你 → 做最终决定

> **铁律**: 每个 PART 都有固定输出模板。模板里的每行 `[ ]` 必须填，填不了的写"未知(原因)"。禁止合并、跳过、总结。

[4] 缺数据 ≠ 跳过 — 缺的字段填"未知 — [尝试过的来源]"，不要省略整行
```

# PART 0 — 宏观环境：定仓位天花板

> **做什么**: 看大环境，算总仓位上限。不淘汰任何标的。
> **谁做**: Hermes 每日拉 W&W + 每月更新宏观。Claude Code 查表。

## 0.1 L0 情绪温度计（W&W）

```
数据源: Hermes → ww_indicator.py（每日跑）

W&W 读数    区间           压缩系数   含义
0-20       Very Bullish    ×1.2     极度恐惧，温和上浮（防止踏空）
20-40      Bullish         ×1.0     偏恐惧，不压缩
40-60      Neutral         ×1.0     中性，不干预
60-80      Bearish         ×0.6     偏亢奋，收一收
80-100     Very Bearish    ×0.4     极度亢奋，大幅收缩

底部设计: ×1.2而非×1.5 — A股底部是区域不是一根线，加一点不加满。
         回测支撑: 2011.9(20.7)、2019.1(32.2)、2024.9(29.8)三次大底皆在Bullish区。

当前: W&W = 90.3 → ×0.4
→ 市场亢奋。不是不能买，是仓位要收敛。
```

## 0.2 L1 SP500 极端风险

```
数据源: Hermes → compute_sp500_score_v4.py
  （读取 风控模型0415.xlsx，RV20替代VIX×1.2系数，z-score 364周滚动窗口）
仅在全球危机时介入（L4地狱/L5炼狱）→ 一票否决，仓位强制 ≤ 35%/15%
日常不介入。
当前: L3 困难 → 不介入

## 0.3 L2 宏观象限

```
数据源: CPI/PPI/PPIRM/PMI（国家统计局，月度） + Z-Credit/Z-Monetary（用户月度PDF）
  信用维度依赖用户PDF — akshare/East Money 无法替代。
  Hermes 每月更新 → "帮我更新L2宏观"
  降级模式（用户PDF未更新时）:
    信用方向公开替代: 社融存量增速YoY + M1-M2剪刀差
    → 可判断信用"扩张/收缩"方向，不能算精确仓位上限
    → 标注"公开数据近似 — 精度降一级"，六象限靠方向+通胀两维推断
    → 仓位上限取保守值: 50%（不确定时不给80%）

六象限 → 仓位上限 + 不碰方向:

宽信用扩张 / 信用修复型再通胀 / 低通胀稳增长 → 80%
紧信用放缓                                      → 55%
供给冲击型滞胀 / 通缩式下行                       → 50%

当前: 供给冲击型滞胀（第5月）→ 50%
不碰方向: 成本敏感型中游制造业（PPI-PPIRM=-1.9pp）
  → L3 翻译为具体赛道黑名单 → PART 1 自动过滤
```

## 0.4 仓位天花板（汇总计算）

```
L5_仓位天花板 = L0_WW压缩 × L2_宏观上限 × 100%
             = 0.4 × 50% × 100%
             = 20%

IF L1 = L4(地狱) / L5(炼狱) → 天花板 = L1_硬帽子(35% / 15%)，覆盖上述公式
当前 L1 = L3(困难) → 不介入，日常公式生效

当前环境允许的总仓位: 最高 20%

规则:
- 这是天花板，不是目标。找不到好标的 → 现金就是持仓
- 单票 ≤ 10%（天然上限，除非你明确说可以更高）
- 同族子赛道合计 ≤ 单票上限 × 1.2

现金底仓（强制最低现金比例，天花板之外的独立约束）:
  W&W > 80（极度亢奋）→ 现金 ≥ 30%
  W&W > 60（偏亢奋）   → 现金 ≥ 10%
  其余                   → 无强制
  当前 W&W=90.3 → 总仓位≤20% 且 现金≥30%
```

**输出**:
```
PART 0 结论: 总仓位 ≤ 20% | 市场亢奋，收着点 | L2滞胀，不碰成本敏感型中游
```

## 1.2 L3 赛道方向（定性）

```
IF L3_判定 == "[不碰]" → STOP。宏观硬约束，不看。
  豁免: GPM ≥ 30%（L3黑名单三层分类之GPM兜底）— 高毛利=定价权=成本传导
  人工推翻: 若你确认它是错杀 → PART 6 [L1] 审问，说明理由，记录在案
IF L3_T4 逃顶信号（整板块）→ 历史 3/3 触发每次跌 >45%。STOP。不看。
  T4豁免（子赛道独立阿尔法）:
    若标的 SSHY细分 ≠ T4触发主赛道 且 GPM ≥ 30%
    → 不自动STOP，标记"T4板块逃顶但子赛道豁免" → 进入PART 6 [L2] 审问
    例: 半导体存储触发T4，但半导体设备(SSHY不同) GPM≥30%→可豁免
IF L3_T2 强反转 → 绿灯优先看。
其余 → 正常看。

数据源: Hermes L3 产业周期择时（创业板300只 6指标 Lead-Lag z-score）
  如不可用 → 跳过此步，标注"L3 z-score 数据缺失"

信号触发标准:
  T4（高置信顶）: Δdiv < -0.8 + Lag_z > 0  → 整板块 STOP
  T2（强反转）:   分歧转正 + Δdiv > +0.5    → 绿灯优先
  T2（弱反转）:   分歧转正 + Δdiv < +0.2    → 正常研究，不升级
  无信号: 按正常流程
```

# PART 2 — 个股排雷：4 条硬淘汰

> **做什么**: 只拦真暴雷。过了这 4 条就不再淘汰——后面只是审你。
> **谁做**: Hermes 拉财务数据 → Claude Code 逐条检查
> **数据源**:
>   BS/CF → 新浪 vDOWN (fetch_report.py — HTTP GET, GBK TSV)
>   PL/比率 → akshare THS (fetch_report.py — stock_financial_abstract_ths)
>   NonRec% → 归母-扣非推算 或 10jqka年报审计表 / 国信证券研报
>   审计意见 → 10jqka 年报审计表
>   大股东质押 → 东方财富股东页面

## 硬淘汰（触发任一条 → STOP）

```
[ ] 审计意见非标
    → STOP。审计师都不信报表，不用往下看。

[ ] NonRec% > 80%
    → STOP。利润靠变卖家当，公司主业不赚钱。

[ ] 商誉/净资产 > 30% + 审计意见非标（联合触发）
    → STOP。减值暴雷只是时间问题。

[ ] 大股东质押 > 80% + 股价距质押平仓线 < 20%
    → STOP。大股东自己都快爆了。
```

## 标记（不淘汰，进 PART 3 时会提醒你）

```
[ ] 商誉/净资产 > 30%              → ⚠️ 减值风险
[ ] 大股东质押 > 50%               → ⚠️ 爆仓风险
[ ] 有息负债/净资产 > 70%（制造业） → ⚠️ 债务压力
[ ] NonRec% 10-30%               → ⚠️ 需用扣非口径
[ ] CFO/NP < 0.5 连续两季         → ⚠️ 利润含金量不足 → 查三类豁免
```

**输出**:
```
PART 2 结论: 通过 / STOP
          标记项: [列表] 或 "无"
```

## 3.3 周期与估值

```
周期类型: [强/中/弱/非周期]  → 决定用什么估值方法
  强周期: PB/PS 分位为主，禁用绝对 PE
  中周期: PEG + PB 交叉
  弱/非周期: PEG + PE 分位

行业→周期映射（L3未收录时查此表，L3已标注则优先L3判定）:
  强周期: 煤炭/有色/化工/钢铁/存储/养殖/船舶/新能源上游材料
  中周期: 汽车/机械/半导体设备/封测/功率器件/IDC/电网设备
  弱周期: 医药/必选消费/公用事业/军工电子
  非周期: 软件/AI/创新消费/金融IT/能源IT
  → 边界模糊时取更保守一级（宁做强周期不用PE，不做弱周期错过PB底部）

=== PE陷阱检测（三道防线 + PEG旁路）===

防线① — 强周期PE陷阱（双路径）:

  路径A — 存量PE陷阱:
    IF 强周期 AND PE < 15:
      → 逐条审查: QoQ利润在加速? / 行业CAPEX在收缩? / PB分位<30%?
      → 三项全YES = 周期底部复苏（正常）
      → 任一项NO = 周期顶部PE陷阱 → PART 6 [E1] 审问
    数据: PB分位 ← pb_percentile.py（东方财富历史PB）；行业CAPEX ← 财报附注/同花顺行业数据
    注意: PE<8 才是真正的周期顶部陷阱区（低PE=利润巅峰）
          来源: pe15-backtest.md — 8只强周期股×5年数据回测
          PE 12-20 反而是"甜点区"，不一定有问题

  路径B — Q2预告PE骤降（最隐蔽的陷阱）:
    IF Q2/H1 预告发布后 PE 骤降 ≥ 40%（如 48x→21x）AND 强周期:
      → 强制 PB/PS 分位替代 PE 估值
      → 附加判定:
          CFO/NP < 0.5 → "利润含金量不足，PE骤降是假修复"
          QoQ 增速连续两个季度放缓 → "周期顶部确认"
      → 任一条触发 → 极大风险，PART 6 [E2] 审问
    案例: 江波龙(301308) H1预告 → PE 48x→21x + CFO/NP=-0.74 + QoQ放缓
    表象"变便宜了"，实际是周期顶部利润滞后反映

防线② — 价值陷阱:
  IF PE < 15 AND 营收增速 < 5% AND 非强周期:
    → 低PE + 零增长 = 无限横盘 → PART 6 [V3] 审问

防线③ — 增长陷阱:
  IF 营收增速 > 20% AND ROE 近3年不升反降 AND PE > 40x:
    → 越增长越不赚钱 = 经典 malinvestment
    例外: 重资产行业(IDC/电网/设备) + ROE 6-10% + PE < 30x → 观察豁免
    案例: 奥飞数据 ROE 3.7% + PE 55x + 营收+31.1%且ROE连降 → PART 6 [G1] 审问

=== PEG旁路（纠正"成长被误判为高估"的分类错误）===

触发条件（三条全满足 → 不因PE超标淘汰，走PEG旁路）:
  ① 生命周期 = 成长期 / 导入期（非成熟期/衰退期）
  ② PEG ≤ 1.0 AND NP增速 ≤ 近3年CAGR × 3.0
     // 数据来源: 近3年CAGR ← PART 3.1 三阶营收增速
     //          NP增速 ← 同花顺/东方财富利润表 YoY
     // 第2项防止"单季暴增拉低PEG"假通过
     // 上限×3.0: 增速可以快但不能离谱
     // 例: 通富微电 Q1 NP+225%, 近3年CAGR=15% → 225% > 45%(15%×3.0) → 不满足
  ③ 板块逻辑 = 国产替代 / 技术垄断

  通过 → 标记 [PE超标-PEG旁路]
  不通过 → 按正常PE超标处理，PART 6 [V3] 审问
```

> **不是建议，是计划。** 执行计划你自己定，框架只帮你检查一致性。

## 5.1 买入计划

```

  [ ] 底仓未盈利前不开加仓
  [ ] 浮亏头寸永不加仓
```

## 5.2 止损设置

```
绝对止损:
  亏 -8%（入场价）→ 无条件减仓 50%
  亏 -12% → 无条件清仓
  触发后 3 个交易日内执行完毕

追踪止损（浮盈 ≥ 20% 启动）:
  梯度收紧: 1.5×ATR → 1.0×ATR → 0.8×ATR
  → 涨得越多，止盈越紧。利润不会全部回吐给市场。

技术止损:
  MA30 有效跌破（价在MA30以下 + MA30方向 DOWN）→ 双确认 B 条件触发
```

## 5.3 卖出双确认（A+B）

```
A 条件（基本面）:
  强A（清仓级）: L3 z-score 连续两季下行 > 0.15 / PE 分位 > 90%
    数据: L3 z-score ← 创业板300只 6指标 Lead-Lag（L3 产业周期择时，非个股z-score）
          PE分位 ← 东方财富历史PE页面（近5年）
  弱A（减仓级）: 催化剂到期未兑现 / 季报低于预期

B 条件（技术面）:
  收盘连续两日跌破 MA20 或 MA20 拐头下行

  B条件内部分级（基于 5 日 MA20 斜率）:
    强B: MA20 拐头下行 → 全清
    弱B: MA20 仍在上升 → 按斜率四档:
      ≥1.0（强上升）→ 不执行 | 0.5~1.0 → 减仓 25%
      0.1~0.5 → 减仓 50% | <0.1（极弱）→ 按强B全清
  恐慌日修正: W&W<20 或 CSI300 单日跌 >3% → 弱B降级观察，强B不变

执行:
  仅 A → 设止盈，不动手
  仅 B → 按强弱B分级减仓
  A+B 同时满足 → 执行减仓/清仓
  绝对止损 8%/12% 优先于双确认
```

# PART 6 — 纪律审问：你扛得住自己的逻辑吗

> **做什么**: 前面 5 层的数据和计划都有了。现在逐条审你——不是淘汰，是逼你面对自己。
> **规则**: 每一条警告 → 问你一个问题 → 你必须回答 → 回答被记录。
> **你回答了，就过。你回答不了——你自己知道该怎么办。**

## 6.1 周期位置

```
[E1] 强周期 + PE < 15:
     "PE=XX，周期底部复苏还是周期顶部利润冲顶？你怎么区分的？"

[E2] 强周期 + Q2预告PE骤降 ≥ 40%:
     "PE从XXx骤降到YYx，估值修复还是周期顶部利润滞后？CFO/NP是多少？"
```

## 6.2 估值

```
[V1] PE > 同行中位 × 1.5:
     "PE比同行贵50%+。你买的溢价对应什么？护城河？技术垄断？说清楚。"

[V2] PE > 40 AND GPM < 20%:
     "高PE+低毛利极其危险。低毛利说明没定价权，凭什么享受高估值？"

[V3] PEG > 1.5:
     "成长撑不起估值。你在赌未来增速大幅提高？依据是什么？"

[V4] 强周期 且 你在用PE而不是PB/PS:
     "强周期品该看PB/PS分位。你现在用PE可能恰恰在看陷阱。"
```

## 6.3 生意质量

```
[B1] GPM < 15%:
     "毛利率不到15%，赚辛苦钱。你确认这个生意值得长期持有？"

[B2] ROE < 10% 连续两季 且 非重资产:
     "ROE不到10%，股东每块钱只赚X分。你买的理由？"

[B3] CFO/NP < 0.5 连续两季 且 不属三类豁免:
     "现金流远低于利润。利润可能是纸面富贵。你怎么看？"

[M1] 护城河致命风险:
     "你买的是它的护城河。但护城河最怕什么？
      技术垄断 → 技术被替代。客户绑定 → 大客户流失。
      规模成本 → 产能过剩。你说它是哪一类？最怕什么？
      有没有迹象表明这个风险在接近？"

[G1] 营收增速 > 20% + ROE 近3年不升反降 + PE > 40x:
     "增长陷阱——越增长越不赚钱。营收靠capex堆出来，ROE反而被资产膨胀压制。
      你确认这不是malinvestment？"
```
