## 1. L4 是干什么的

**一句话：从海选到精挑，输出个股的战略仓位上限。**

L4 是整个框架的体积大户——13 个 Stage 串联成一条流水线，前半段（Stage 0-5b）做减法（淘汰不合格的），后半段（Stage 6A-7）做加法（深度分析幸存者）。

核心原则：

```
前半段只淘汰，不评级。Stage 0-5b 期间禁止出现 A/B+/B/B-/C/D 评级词。
每个 Stage 一个节点，零淘汰也必须出现。
```

在框架中的位置：

```
L0  W&W 情绪       → ×0.4 刹车
L1  SP500 风控     → 不介入 (极端时一票否决)
L2  六象限宏观      → 50%帽子 + 不碰清单
L3  产业周期        → T2已触发 + BK黑名单预过滤
L4  选股            → 13 Stage 流水线 ← 本层
L5  交易            → 执行
```

## 3. Stage 0 — Q1 报告五级打分

### 干什么
用 Q1 财报把全行业分成五档。最差的一档直接出局，不进后续。

### 打分公式

```
三指标加权:
  ① Q1 营收增速 YoY（权重 35%）
  ② Q1 扣非净利润增速 YoY（权重 35%）
  ③ Q1 GPM 绝对值 + 环比变化（权重 30%）
```

### 五级定义

| 级别 | 条件 | 操作 |
|------|------|------|
| L5 强烈推荐 | 三指标全 > 20%，GPM 不降 | 优先进入扫描 |
| L4 推荐 | 两指标 > 20%，GPM 不降 | 进入扫描 |
| L3 中性 | 至少一指标 > 10%，无重大恶化 | 进入扫描 |
| L2 审慎 | 三指标 0-10%，或单季恶化 > 30% | 仅在有催化剂时进入 |
| L1 回避 | 营收负 + 净利负，或 GPM 两季恶化 > 5pp | **淘汰** |

### 数据源
全市场概念分类表_v3.csv 的 Q1 季报字段。若 CSV 中无 Q1 数据，标注 `[数据缺失]` 并降一级为 L3。

### 输出模板

```
Stage 0 完成
  全量成分股: N 只
  L5: X只  L4: Y只  L3: Z只
  L2(需催化剂): A只  L1(回避): B只
  进入 Stage 1: X+Y+Z 只
```

## 5. Stage 2 — L3 黑名单预过滤 + 概念关联度

### 干什么
两步过滤。先踢掉 L3 滞胀黑名单里的 [不碰]，再按概念匹配度筛掉不相关的。

### 2.0 L3 黑名单预过滤 (v1.2 新增, 2026.7.5)

```
数据源: L3_滞胀期BK黑名单_v1.2.csv (5511只)
  columns: code, name, SW1, SSHY, 主赛道, Tier, GPM, PE, 市值, 概念标签, L3_判定, L3_来源

过滤规则:
  [不碰]      → 直接淘汰
  [T0限制]    → 保留但标记 T0 (不进重仓)
  [强周期]    → 保留但标记 强周期 (进入 Stage 3.5)
  不在CSV中   → 无罪推定, 通过
  豁免: 无 — L3不碰清单是L2宏观定性约束的硬翻译

三层分类体系:
  SW1行业级 (~2213只): 医药生物→保留, 电子→保留, 建筑材料→不碰...
  SSHY细分级 (~822只): 通用设备→不碰, 专用设备→保留, 工程机械→不碰...
  GPM兜底 (~1276只): GPM>=30%→保留, 20-30%→保留标记, <20%→不碰
```

### 2.1 概念关联度过滤

```
三条件 OR 关系，满足任一即通过:

  条件 A — 主赛道直接匹配:
    标的"主赛道"字段 == 用户指定的赛道名 → Tier1

  条件 B — 概念标签关键词匹配:
    标的"概念标签"字段 与 目标赛道核心概念有 ≥ 2 个交集 → Tier2

  条件 C — 上下游传导关联:
    标的在 MULTI_TRACK 中与目标赛道存在上下游关系 → Tier3

淘汰: 三条件全不满足
降级: 营收占比 < 5% 的主赛道 → 降为 Tier3
```

### 输出模板

```
Stage 2 完成
  输入: N 只
  [2.0] L3黑名单:
    → 淘汰(不碰): X只  T0限制: Y只  强周期: Z只
  [2.1] 概念关联度:
    → Tier1(直接匹配): A只  Tier2(概念交集): B只
    → Tier3(上下游关联): C只  淘汰(无关联): D只
  通过: 剩余 只
```

## 6. Stage 3 — 多周期 K 线 + 财务拉取

### 干什么
月线→周线→日线，顺序不许颠倒。真 DOWN 的直接踢。

### 月线先看

```
① 连阳透支:
   月线 ≥ 4 连阳 → 标记
   月线 ≥ 6 连阳 → 淘汰

② 乖离率:
   MA20 乖离 > 25% → 标记
   MA30 乖离 > 40% → 淘汰

③ 量价背离:
   价格新高 + 成交量萎缩 > 30% → 标记

标记 ≥ 2 条 → 淘汰
```

### 周线再看

```
MA20 方向 + 趋势完整性
```

### 日线最后

```
MA20/MA30/MA60 斜率 + 偏离度 + 量价配合

四类定性仓位系数:

  真DOWN      淘汰     MA20斜率 < -0.5 AND MA30 DOWN
  回调机会     ×0.3     MA20↓ BUT MA30↑ + 缩量
  蓄力趋势     ×0.7     MA20走平(-0.5~+0.5) + MA30走平或微升 + 缩量横盘
  追高风险     ×0.2     偏离MA20 > ATR阈值 OR 股价分位 > 90%
```

### 输出模板

```
Stage 3 完成
  输入: N 只
  → 真DOWN: X只
  → 月线透支: Y只
  → 量价背离: Z只
  幸存: N-X-Y-Z 只
```

## 7. Stage 3.5 — 周期股强制拦截

### 干什么
防止 8 月 Q2 财报批量更新后，周期顶部暴利 → TTM PE 被动下降 → 低 PE 当价值股买入。

### 路径 A — 存量 PE 陷阱

```
IF 强周期 AND PE < 15:
  审查①: QoQ 利润增速 > 前两季均值?     [YES/NO]
  审查②: 行业资本开支 YoY < 0?          [YES/NO]
  审查③: PB 分位 < 30%?                  [YES/NO]

  三项全 YES → "周期底部复苏" → 保留，走 PB/PS 估值
  任一项 NO → "周期顶部 PE 陷阱" → 淘汰
```

### 路径 B — Q2 预告 PE 骤降陷阱

```
IF Q2/H1 预告发布后 PE 骤降 ≥ 40%:
  强制使用 PB/PS 分位估值，禁用 PE
  附加判定:
    CFO/NP < 0.5 → "利润含金量不足"
    QoQ 增速连续两季放缓 → "周期顶部确认"
  任一条触发 → 淘汰

案例: 江波龙(301308) H1预告 → PE 48x→21x + CFO/NP=-0.74 + QoQ放缓 → 淘汰
```

### CFO/NP < 0.5 三类豁免

```
① 产能扩张: 固定资产/总资产 > 30% + 在建工程 YoY > 50%
② 战略性备货: 存货/总资产 > 40% + 存货 YoY > 营收 YoY
③ 项目型确认: 合同负债 YoY > 50%

不属以上三类 → 淘汰/降级
```

### 价值陷阱

```
PE < 15 + 营收增速 < 5% → 淘汰 (PEG = 15/5 = 3.0 > 框架 PEG≤1.0)
非周期行业的低PE低增长 = 无限横盘
```

### 输出模板

```
Stage 3.5 周期拦截完成
  输入: N 只
  强周期标记: X 只  中周期标记: Y 只

  [路径A] PE<15 存量PE陷阱:
    触发二次审查: Z 只
    → 周期底部复苏(通过): A 只
    → 周期顶部PE陷阱(淘汰): B 只

  [路径B] Q2预告PE骤降≥40%:
    触发PB/PS强制替代: C 只
    → 附加淘汰: D 只

  CFO/NP豁免触发: E 只
  价值陷阱淘汰: F 只
  幸存: N-淘汰 只
```

## 10. Stage 5b — 增长陷阱 + 重资产 ROE 联合审查

### 干什么
拦截"越增长越不赚钱"的标的——营收增长靠 capex 堆出来，ROE 反而被资产膨胀压制。

### 判定树

```
IF 营收增速 > 20%
   AND 近 3 年 ROE 不升反降（或持续 < 5%）
   AND PE(TTM) > 40x:

  ├── 非重资产行业 → 直接淘汰（⑤ 增长陷阱）
  │    案例: 某软件股 营收+25% / ROE 6%→4%→3% / PE 60x → 淘汰
  │
  └── 重资产行业 (IDC/电网/设备/封测/IDM):
        ├── ROE 6-10% + PE < 30x + 产能投产在即 → 观察豁免
        │    标注: "等待ROE拐点确认"
        │
        └── 不满足豁免条件（ROE < 5% 或其他两条触发）→ 淘汰
             案例: 奥飞数据 ROE 3.7% + PE 55x + 营收+31.1%且ROE连降 → 淘汰
```

### 输出模板

```
Stage 5b 增长陷阱+重资产ROE审查完成
  输入: N 只
  → 增长陷阱淘汰(非重资产): A 只
  → 重资产: 触发联合审查: B 只
      → 淘汰(三条全中): C 只
      → 观察豁免: D 只
  标记不触发: E 只
  幸存(含观察): N-A-C 只
```

## 11. Stage 6A — 元数据预处理

### 干什么
对幸存者一次性标注生命周期标签 + 概念权重。后续所有 Stage 复用。**终身只用做一次。**

### 生命周期四档

| 阶段 | 营收增速 | 行业渗透率 | PE | 估值容忍 |
|------|---------|-----------|----|---------|
| 导入期 | > 30% | < 20% | 可能为负 | — |
| 成长期 | 15-30% | 20-50% | 偏高 | PE ≤ 28 |
| 成熟期 | 5-15% | > 50% | 稳定 | PE ≤ 23 |
| 衰退期 | < 5% | > 80% | 偏低 | — |

### 概念权重计算

```
core_weight = 概念标签交集数 / 目标赛道核心概念总数
edge_weight = 边缘概念标签数
权重总计 = core_weight × 0.7 + min(edge_weight × 0.3, 0.3)
```

### 输出模板

```
Stage 6A 元数据预处理完成
  输入: N 只
  生命周期分布:
    导入期: A只  成长期: B只
    成熟期: C只  衰退期: D只
  概念权重达标(≥0.5): X只
  权重不足(<0.5): Y只 → 标记但不淘汰
```

## 12. Stage 6B — 板块细分拆解

### 干什么
确定子赛道归属，避免"伪分散化"。子板块拆解 BEFORE 评级。

### 三步

```
1. 子赛道归属判定:
   从 多赛道权重.json 读取营收占比 → 归属到最大子赛道
   无 JSON → 从 CSV 概念标签推断

2. 竞争格局快照:
   目标公司 vs 同子赛道对手: GPM / 营收增速 / ROE / 市占率

3. 同族子赛道聚类:
   同一"族"子赛道 → Stage 7 用 Iron Rule 16 约束总仓位
   总上限 = MAX(各标的仓位上限) × 1.2
```

## 13. Stage 6C — 单票深度分析（择股 7 步法）

### 干什么
L4 的核心。每只幸存者走完整 [0]-[9]，100 分制打分。

### [0] NonRec% 前置闸门 + 三项排雷 (MANDATORY FIRST)

```
NonRec% = 非经常性损益 ÷ |归母净利润|

IF NonRec% < 10%   → 盈利干净, 通过
IF NonRec% 10-30%  → 需用扣非 PE/ROE, 标记
IF NonRec% > 80%   → 直接淘汰

三项排雷:
  (1) 商誉/净资产 > 30% → 仓位自动降一级
      商誉/净资产 > 30% + 审计非标 → 联合触发淘汰
  (2) 资产负债率红线:
      制造业/周期: 有息负债/净资产 > 70% → 高风险
      消费类: > 60% → 高风险
      CFO/NP < 0.5 连续两季 + 红线触发 → 观察池
  (3) 大股东质押 > 50% → 标记
      审计意见非标 → 直接淘汰
```

---

### [1] 单季度财务拆解（8-13 季度）

```
增长类型判定 (三阶营收增速):
  加速型: 1年/2年/3年 CAGR 全 > 15% 且加速        ← 最优
  稳定型: 全 > 15% 但减速
  爆发型: 1年 > 30% 但 2/3年 < 10%   → 一次性订单?
  停滞型: 1年 < 5%                    → 触发业绩预警

GPM/NP 恶化预警:
  连续 2 季环比下行 → 扣分
  例外(以价换量): GPM下行但营收增速环比扩大 ≥ 5pp → 豁免

季节性异常:
  Q4 GPM < 3年均值 5pp → 会计洗澡嫌疑
  Q4 营收 > 3年均值显著 → 年末突击确认收入
```

---

### [2] 资产负债表 + 现金流

```
议价权四象限:
  应收↓ + 应付↑ = 两头吃 → 加分
  应收↓ + 应付↓ = 对下游有议价 → 中性
  应收↑ + 应付↑ = 对上游有议价 → 警惕
  应收↑ + 应付↓ = 被双向挤压 → 扣分

FCF (自由现金流):
  重资产: FCF 连续两年为负 → "融资依赖"标记
  轻资产: FCF 连续三年为负 → 淘汰

CFO/NP < 0.5: 按三类豁免审查 (对齐 Stage 3.5)

合同负债双维度:
  同比连续两季下降 → 下游需求走弱 → 扣分
  同比上升 + 环比平稳 → 健康
```

### [3] 技术面（月→周→日线）

```
股价分位:
  3Y > 80% + 5Y > 80% → 高位压缩 ×0.5
  3Y > 80% BUT 5Y < 50% → 底部反弹, 不压缩
  3Y < 30% → 低位区

筹码:
  换手率 < 2%: 稳定  2-5%: 正常  5-10%: 关注  > 10%: 异常
  套牢盘 > 60% → ×0.5

仓位系数: 真DOWN淘汰 / 回调×0.3 / 蓄力×0.7 / 追高×0.2 / 正常×1.0
```

### [4] 产业链 + 竞争格局

```
行业景气度: 上行/平稳/下行

交叉验证:
  公司"加速型" + 行业"下行" = 独立阿尔法 (加分, 抢份额)
  公司"稳定型" + 行业"上行" = 随波逐流 (不加分)

政策风险: 产能受限/集采/反垄断/出口壁垒

对手对标:
  目标 GPM > 同行中位 ≥ 3pp + ROE > 同行 ≥ 5pp → 护城河数据支撑
  目标 GPM 和 ROE 均 < 同行 → 无护城河 → Step B 自动降一级
```

### [5] A-G 核心论据（100 分制）

| Step | 评分项 | 满分 | 判定依据 |
|------|--------|------|---------|
| **A** | 生意质量 | 15 | GPM四档/产品标准化/客户粘性/议价力/商业模式 |
| **B** | 护城河 | **20** | 规模/客户/成本/技术 四壁垒。权重最高—决定长期估值中枢 |
| **C** | 增长引擎 | 15 | 来源拆分/持续性/增速斜率/贝塔vs阿尔法 |
| **D** | 财务质量 | **20** | GPM趋势/NP稳定/NonRec/ROE杜邦+隐藏校验 |
| **E** | 周期位置 | 10 | 四类周期+估值强制规则+分类错误识别 |
| **F** | 催化剂 | 10 | 四类+三要素硬约束+失效规则 |
| **G** | 风险控制 | 10 | 单最大风险+概率×损失+预警指标 |

#### Step A — 生意质量 (15分)

```
A1. GPM 四档:
  > 30%    → 满分，天然享受估值溢价
  18-30%   → 合格，天然上限 B+
  12-18%   → 扣分，竞争激烈
  < 12%    → 预警，天然上限 C

A2. 产品标准化: 非标定制 → 加分；通用大宗 → 扣分
A3. 客户粘性: 认证周期长/技术绑定 → 加分；前五大>50% → 硬扣分
A4. 议价力: 原材料涨价周期中GPM未显著下滑 → 有议价力
A5. 商业模式: 预收型 > 销售型；重资产+高有息负债 → 扣分
```

#### Step B — 护城河 (20分)

```
四类壁垒:
  B1 规模壁垒: 市占率 + 单位固定成本
  B2 客户壁垒: 认证周期/排他协议/头部客户名录
  B3 成本壁垒: 自研自制率/自动化产线/上游锁料
  B4 技术&品牌: 研发费用率/发明专利/独家工艺

硬约束:
  ≥ 2 类壁垒成立 → 可纳入重仓池
  ≤ 1 类壁垒     → 仅限观察仓 ≤ 10%
```

#### Step C — 增长引擎 (15分)

```
C1 增长来源拆分: 产品维度(销量/新品类/提价) + 下游维度(存量/新行业/海外)
C2 持续性验证: 渗透率(>70%=天花板) + 产能匹配度 + 订单能见度
C3 增速斜率: 加速型(加分) / 稳定型(中性) / 减速型(扣分)
C4 贝塔vs阿尔法: 公司增速 > 行业5pp → 阿尔法；≈行业 → 贝塔；<行业 → 掉队
```

#### Step D — 财务质量 (20分)

```
D1 GPM趋势: 近3年平稳/上升 → 加分；连续2季下行 → 扣分
D2 NP率稳定性: ±15%内(优秀) / 15-30%(中性) / >30%(扣分)
D3 NonRec%校验: <10%干净 / 10-30%用扣非 / >80%淘汰
D4 ROE杜邦: ≥20%优质 / <10%扣分 / 高杠杆驱动 → 风险扣减

隐藏校验:
  CFO/NP > 1 → 利润含金量高
  商誉/净资产 > 30% → 降级
  CFO/NP < 0.5连续两季 → 三类豁免审查

重资产扩张期ROE容忍度:
  ROE<5%+PE>40x+营收>20%且ROE连降 → 淘汰
  ROE 6-10%+PE<30x+产能投产 → 观察
```

#### Step E — 周期位置 (10分)

```
四类周期:
  强周期: 煤炭/有色/化工/钢铁/存储 → 禁用绝对PE, 用PB/PS分位
  中周期: 汽车/机械/半导体设备 → PE辅助, PEG+PB交叉
  弱周期: 医药/必选消费品 → PEG+历史PE分位
  非周期: 软件/AI/创新消费 → PEG+历史PE分位

四类市场分类错误:
  ① 周期被误判为成长 → 产能周期+SOTP
  ② 成长被误判为周期 → SOTP分部>市值30%+
  ③ 重资产被误判为轻资产 → 对比两种PEG
  ④ REIT/处置收益PE虚低 → 强制用扣非PE

PE骤降陷阱⑥:
  Q2预告后PE骤降≥40% + 强周期 + CFO/NP<0.5
  → PE骤降是利润周期性冲顶的滞后反映
  → 强制PB/PS替代
```

#### Step F — 催化剂 (10分)

```
四类:
  ① 业绩催化: 财报超预期/订单大增 → 验证点: 季报
  ② 产品催化: 新品/头部客户认证 → 验证点: 客户公告
  ③ 客户&业务: 海外客户/并购/产能投产 → 验证点: 公司公告
  ④ 政策&行业: 补贴/产业扶持/国产替代 → 验证点: 政府文件

硬约束: 至少1项最多3项，每项写具体事件+验证时间
禁止空泛: "行业前景向好""有望受益国产替代"

失效规则:
  催化剂在约定时间未兑现 → 重新评估
  连续两个落空 → 考虑减仓
```

#### Step G — 风险 (10分)

```
三要素强制模板:
  ① 单最大风险: 只列一个最致命的
  ② 发生概率: 低(0-30%) / 中(30-60%) / 高(60-100%)
  ③ 损失幅度: 归母净利润下滑 <15% / 15-30% / >30%

风控:
  高概率+下滑>30% → 致命 → 仓位≤10%
  中概率+下滑15-30% → 重大 → 不可重仓
  低概率+下滑<15% → 温和 → 不影响基准

预警指标前置: 买入前想好观察指标
  一旦触发预警 → 提前减仓，不等风险兑现
```

#### 统一打分 → 评级映射

```
≥ 85 → A级    重仓 25-35%    全优, 壁垒 ≥ 3 类
75-84 → B+级  基准 15-25%    护城河清晰
70-74 → B级   基准 10-20%    壁垒成立但非龙头
60-69 → B-级  观察 ≤ 10%     有亮点但硬伤明显
< 60 → C/D    淘汰            不纳入
```

### [7] 估值分析

```
三情景:
  保守: 绑定具体假设 (下游需求-10%、ASP降5%)
  基准: 当前趋势外推
  乐观: 绑定 Step F 可验证催化剂

PE: 当前 + FY26E + FY27E + vs 5年中位 + vs 同行

PEG联动:
  净利润 PEG = PE / NP增速
  FCF PEG = PE / FCF增速
  重资产: 以 FCF PEG 为准
    NP PEG < 1 但 FCF PEG > 2 → 估值陷阱

绝对估值:
  非周期: DCF + PE 双向校验, 差异 > 30% → 质疑假设
  强/中周期: PB/PS 分位
    PB分位 < 30% → 偏低(加分)
    PB分位 > 70% → 偏高(减分)
```

### [8] 买点分析 & 交易规则

```
买入区间: MA20/MA30 技术位, 优先 TREND_START

三级仓位:
  A级:  基准10-25%, 重仓上限35%
  B+级: 基准8-20%, 上限25%
  B级:  基准5-15%, 上限20%
  B-级: 观察≤10%, 禁止基准仓
  C级:  仅观察≤5%
  D级:  不纳入

加仓双硬约束:
  ① 基本面逻辑未证伪 + 最近一期季报无"低于预期"
  ② 技术面回踩关键支撑企稳: MA20/MA30 缩量回踩
  绝对禁止浮亏加仓。底仓未盈利前不开加仓。浮盈>10%才开进攻仓。

止损:
  绝对: 亏损≥8% → 减仓50%, ≥12% → 清仓, 3交易日执行
  技术: MA30有效跌破 → 触发双确认B条件
  两者互补: 技术未破但亏损8% → 框架可能看漏, 先减

卖出双确认:
  A: 框架否定(赛道降级/基本面恶化/催化剂失效)
  B: 技术破位(MA20/MA30有效跌破+量价验证)
  8%绝对止损优先于双确认制
```

## 14. Stage 6.5 — 质量闸门四问

### 干什么
定量打分之后，定性把关。打分系统 = 定量，质量闸门 = 定性——互补而非二选一。

```
Q1: 这个生意的质量配得上评级吗？
Q2: 和同赛道其他标的横向对比如何？
Q3: 如果是我的钱我会买吗？
Q4: 有没有遗漏的关键信息？（数据缺口）

任一答案为"否":
  → 手动降级至观察仓 (≤10%)，不执行原评分对应的重仓配置
  → 标注: 闸门否决 — [原因]
```
