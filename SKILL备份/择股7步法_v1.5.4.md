# 择股7步法（7-Step Thesis）

单票深度分析标准流程。对目标公司从财务质量、生意模式、护城河、增长、周期、催化剂、风险七个维度做全面审查，最终给出评级 + 买点分析 + 核心假设。

**三层结构：**

```
[0] 前置校验         ← 第一道防线（雷股直接拦截）
[1]-[4] 数据准备层    ← 财务/技术/产业链数据拉取
[5] A-G 核心论据层   ← 7维度定性+定量判断 ← 核心
[6]-[9] 应用输出层    ← 估值/买点/仓位/Lazy-Check
```

## [0] NonRec% Pre-Check 前置校验（MANDATORY FIRST）

> **v4.2 同步提示：** 当本 skill 被 `小齐股市框架` Stage 6C 调用时，[0] NonRec% 前置闸门由框架层执行，本 skill 从 [1] 开始。独立使用时执行完整 [0]-[9] 流程。输出时标注执行模式（框架调用/独立执行）。

### 原规则

- 扣非/归母 < 70% → 通过
- NonRec > 30% → 所有PE/ROE必须用扣非
- NonRec > 80% → 直接淘汰

### NonRec% 计算公式

```
NonRec% = 非经常性损益 ÷ |归母净利润|
```
绝对值分母，避免亏损股负净利导致统计口径混乱。

### 前置排雷（与本步骤同级，不后置）

**(1) 商誉/净资产 > 30%**

- 高商誉公司一旦业绩不及预期极易大幅减值，必须前置标记
- 仓位上限自动降一级：A→B+，B+→B，B→C
- 不自动淘汰，但必须在 Lazy-Check 中注明商誉风险
- 商誉/净资产 > 30% + 审计意见非标 → 直接淘汰（联合触发）

**(2) 资产负债率红线**

使用**有息负债/净资产**（非总负债率），避免经营性负债（应付账款/预收款）误杀。

```
制造业/周期股: 有息负债/净资产 > 70% → 标记高风险
消费类:        有息负债/净资产 > 60% → 标记高风险
```

触发后：
- CFO/净利 < 0.5 连续两季 + 红线触发 → 直接进入观察池，禁止重仓
- CFO/净利 > 1 → 标注风险但不自动降级

**行业豁免：**
重资产运营模式（IDC/电网/机场/高速公路）且 CFO/净利 > 1 → 豁免至有息负债/净资产 < 80%。

**(3) 暴雷引用**

- 大股东质押率 > 50% → 标记，Lazy-Check 注明
- 审计意见非标 → 直接淘汰

## [1] 单季度财务拆解（8-13季度）

- 每个季度单独拆出营收/净利（不依赖累计数据）
- 看趋势：QoQ环比 + YoY同比 + NP率变化

### 季节性归一化处理（v1.1 新增）

Q4 单季数据失真（年底集中减值/年终奖计提/年末集中回款），不能单看当季绝对值。**与过去至少 3 年同期均值对比：**
- Q4 GPM 是否低于 3 年均值 5pp 以上 → 会计洗澡嫌疑
- Q4 营收是否显著高于 3 年均值 → 年末突击确认收入嫌疑

### 三阶营收增速校验（v1.1 新增）

```
近1年营收增速 / 近2年CAGR / 近3年CAGR
```

区分增长类型：
```
三阶全>15% 且加速   → "加速型"（最优：长期稳定成长）
三阶全>15% 但减速   → "稳定型"（关注天花板）
1年>30% 但 2/3年<10% → "爆发型"（一次性订单？需验证可持续性）
1年<5%              → "停滞型"（触发业绩预警）
```

### GPM/NP率连续恶化预警（v1.1 新增）

连续 2 个季度 GPM 或 NP 率环比下行 → 扣分，纳入 Step D 财务质量扣分项。

**例外（以价换量）：** GPM 下行但营收增速环比扩大 ≥5pp → 豁免。主动降价抢份额不是扣分项。

## [2] 资产负债表 + 现金流

- 存货/总资产比例（是否积压）
- 应收账款周转天数（是否恶化）
- 经营CFO/净利润（是否>1，利润含金量）
- 固定资产/在建工程（产能扩张节奏）

### 上下游议价能力量化（v1.1 新增）

**应付账款周转天数：** 结合应收周转，判断公司对上下游的议价权。

```
议价权象限：

应收↓ + 应付↑ = 产业链最强势（两头吃）      ← 加分
应收↓ + 应付↓ = 对下游有议价、上游弱势         ← 中性
应收↑ + 应付↑ = 对上游有议价、下游弱势（压货） ← 警惕
应收↑ + 应付↓ = 被双向挤压                    ← 扣分
```

### 自由现金流 FCF（v1.1 新增）

```
FCF = 经营现金流 - 资本开支
```

区分"账面盈利"还是"真金白银赚钱"。

```
重资产行业（IDC/电网/设备/封测/IDM）：FCF 连续两年为负 → 标注"融资依赖——靠借钱扩产"，不自动淘汰
轻资产行业（SaaS/设计/服务）：       FCF 连续三年为负 → 直接淘汰
FCF > 0 且连续增长                  → 加分项
```

### 合同负债双维度（v1.1 新增）

**同比看趋势、环比看节奏。** 只看环比会被 Q4 集中招标→Q1 自然回落的季节性误导。

```
同比连续两季下降 → 下游需求走弱前瞻信号 → 扣分+标记"预收款萎缩"
同比上升 + 环比平稳 → 订单储备健康
```

## [3] 技术面（月线→周线→日线，这个顺序不许颠倒）

- **月线**：12m/6m/3m收益 + 距高点 + K线形态
- **周线**：MA20方向 + 趋势完整性
- **日线**：MA20/MA30/MA60 + 斜率 + 偏离度 + 量价配合

### 股价历史分位（v1.2 新增）

当前股价处于近 3 年 / 5 年历史价格分位。即便趋势向上，高位也要控制仓位。

```
3Y分位 > 80% 且 5Y分位 > 80% → 高位压缩：仓位上限 × 0.5
3Y分位 > 80% 但 5Y分位 < 50% → 底部反弹中，不压缩
3Y分位 < 30%                      → 低位区，不压缩
```

**ATH 距离参考：** 当前位置离历史最高价还有多远？ATH 距当前 > 50% 且有基本面改善 → 困境反转候选，加分。

### 筹码结构（v1.2 新增）

```
日均换手率：
  < 2%        → 筹码稳定（加分）
  2-5%        → 正常
  5-10%       → 关注（可能松动）
  > 10%       → 异常活跃（减分——筹码松动或游资炒作）

套牢盘占比（高成交量区间 > 当前价）：
  占比 > 60%  → 上方抛压重，突破需要巨量 → 仓位上限 × 0.5
  占比 < 30%  → 解套压力轻 → 加分
```

### 四类定性标准化仓位系数（v1.2 新增）

| 判定 | 仓位系数 | 条件 |
|------|---------|------|
| 真DOWN | 淘汰 | MA20斜率 < -0.5 且 MA30方向DOWN |
| 回调机会 | × 0.3 | MA20↓但MA30↑ + VP_LABEL=CORRECTION（缩量） |
| 蓄力趋势 | × 0.7 | MA20走平(-0.5~+0.5) + MA30走平或微升 + 缩量横盘 |
| 追高风险 | × 0.2 | 偏离MA20 > ATR自适应阈值 或 股价分位 > 90% |

回调机会若 MA30 方向 DOWN → 不适用，直接降为真DOWN。
蓄力趋势等 MA20 重新拐头向上 → 仓位恢复至 × 1.0。
追高风险止盈收紧至偏离度回归 MA20。

## [4] 产业链 + 竞争格局（web search数据）

### 基本面信息

- 公司做什么的：主营产品+下游应用+客户
- 市场地位：全球/国内市占率

### 行业景气度标签（v1.2 新增）

公司营收增速需要和行业整体对比——公司+30%但行业-10%=是阿尔法不是贝塔。

```
上行：行业整体营收增速 > 15% 且趋势向上
平稳：行业整体增速 5-15%
下行：行业整体增速 < 5% 或连续下降

与 Step E 周期位置交叉验证：
  公司"加速型" + 行业"下行" = 独立阿尔法 → 加分但小心（也可能是抢了对手的份额，不是行业好）
  公司"稳定型" + 行业"上行" = 随波逐流 → 不加分（赚的是贝塔的钱）
```

### 政策风险约束（v1.2 新增）

作为 Step G 最大风险的前置输入。以下行业强制检查：

```
产能受限类：光伏/电池/钢铁/水泥 → 政策去产能 → 天花板明确
集采类：    仿制药/医疗器械/耗材  → 降价压力
反垄断类：  互联网平台/支付       → 业务边界受限
出口壁垒类：半导体设备/高端芯片   → 美国限制 + 国产替代窗口
```

触即标记，不自动淘汰，但必须影响 Step G 的最大风险判断和仓位上限。

### 竞争对手横向对标表（v1.2 新增）

不再只看"行业趋势"。必须列出同行对比，用数据说话：

```
| 公司 | GPM | 营收增速(YoY) | ROE | 市占率 |
|------|-----|--------------|-----|--------|
| 目标公司 | X%  | X%           | X%  | X%     |
| 竞争对手A | X%  | X%           | X%  | X%     |
| 竞争对手B | X%  | X%           | X%  | X%     |

判定：
  目标公司 GPM 高于同行中位 ≥3pp + ROE 高于同行 ≥5pp → 护城河数据支撑
  目标公司 GPM 和 ROE 均低于同行中位 → 无护城河，Step B 证据不足，自动降一级
```

- 竞争对手：谁在抢份额，壁垒在哪
- 行业趋势：需求端景气度 + 供给端产能

### Step A - 生意质量（5 维度量化，避免主观判断）

**A1. GPM 四档打分**

```
> 30%      → 满分，高毛利享受估值溢价
18%-30%    → 合格，常规制造业/软硬件行业，天然上限 B+
12%-18%    → 扣分，行业竞争激烈、产品附加值低，严格控制仓位
< 12%      → 直接预警，高度同质化红海生意，天然上限 C
```

**A2. 产品标准化程度**

```
非标准化：定制化方案、绑定客户场景、需要现场技术支持 → 加分
高标准化：通用零部件/标品/大宗商品化产品、容易价格战 → 扣分

补充校验：是否需要客户现场认证/二次开发？
  需要 → 替换成本高 → 加分
  不需要 → 替换成本低 → 不加分
```

**A3. 客户粘性 + 客户结构双维度**

```
高粘性：客户认证周期长、技术深度绑定、数据迁移成本高 → 加分

客户结构硬约束：
  前五大客户营收占比 > 50% → 即使粘性高也扣分（大客户依赖风险）
  To C 分散客群 / To B 多部门均匀分布 → 加分
```

**A4. 议价力测试（原材料价格传导）**

```
连续两轮原材料涨价周期中，GPM 未出现显著下滑
  → 具备议价力，生意质量优质加分项

原材料涨价 → GPM 随之下降 → 无议价力，成本转嫁能力弱
```

**A5. 商业模式稳定性**

```
轻资产 / 重资产 / 预收型 / 销售型
预收型（高合同负债）→ 生意质量天然优于销售型
重资产 + 高有息负债 → 扣分
```

### Step B - 护城河（4 类壁垒，每项附取证来源，杜绝空泛描述）

**B1. 规模壁垒**

量化验证：
- 营收、产能、出货量在国内/全球行业排名
- 市占率是否行业前 3
- 单位固定成本是否显著低于同行

取证方式：行业白皮书、券商产业数据、竞争对手财报横向对比

**B2. 客户壁垒（认证壁垒）**

细化校验：
- 下游是否进入头部客户合格供应商名录？
- 客户认证周期多久（6个月/1年/3年以上）？
- 是否存在绑定排他性供货协议？

补充：下游客户越集中、准入门槛越高 → 壁垒越强

**B3. 成本壁垒**

校验维度：
- 自研自制率、自动化产线覆盖率
- 上游锁料能力
- 产能规模化摊薄固定成本

对标方式：横向对比同行业 GPM、期间费用率，若持续优于同行 → 成本壁垒成立

**B4. 技术 & 品牌壁垒**

技术端：近 3 年研发费用率、发明专利数量、行业标准参与制定、独家工艺/专利、技术代差领先时间

品牌端：面向 C 端看用户心智占有率，面向 B 端看行业口碑、头部项目标杆案例数量

**硬性约束：**

```
4 类壁垒至少满足 2 类及以上 → 才可纳入重仓池
仅 1 项壁垒或无明确壁垒 → 只能做小仓位观察（≤10%）
```

---

### Step C - 增长引擎（四维验证：来源 + 持续性 + 增速斜率 + 贝塔/阿尔法）

**C1. 精准锁定增长来源（必须拆分到产品 + 下游两个维度）**

```
产品维度：增长来自产品销量提升 / 新品类放量 / 提价？
下游维度：增长来自存量客户订单增加 / 下游行业景气上行 / 海外市场扩张 / 新行业客户导入？
```

禁止笼统描述（如"行业增长带动"）。

**C2. 增长可持续性 3 项量化验证**

```
① 行业渗透率：< 30% → 长期增长空间充足；> 70% → 天花板明确
② 产能匹配度：在手订单增速 vs 产能扩张节奏，是否匹配
③ 订单能见度：合同负债/在手订单增长趋势，预示未来业绩
```

**C3. 增速斜率判定（对齐 [1] 三阶增速）**

```
加速型：连续两季营收增速环比扩大 → 加分
稳定型：小幅波动、整体平稳 → 中性
减速型：连续两季营收增速环比收窄 → 扣分
```

**C4. 贝塔增长 vs 阿尔法增长（对齐 [6] 内生/外生）**

```
公司增速 > 行业增速 5pp 以上 → 阿尔法增长（加分）
公司增速 ≈ 行业增速       → 贝塔增长（不加分——赚的是行业的钱）
公司增速 < 行业增速       → 掉队（扣分——份额在流失）
```

---

### Step D - 财务质量（4 指标 + 杜邦拆解 + 隐藏校验）

**D1. GPM 趋势校验**

```
加分：近 3 年 GPM 平稳震荡/震荡上行
扣分：连续 2 个季度 GPM 环比下行、近 3 年中枢持续下移

交叉验证：结合原材料价格、行业竞争格局，判断下滑是短期扰动还是长期竞争力弱化。
例外（以价换量）：GPM 下行但营收增速环比扩大 ≥5pp → 豁免（对齐 [1] 规则）。
```

**D2. NP 率稳定性**

```
单季度净利率同比波动幅度：

±15% 以内   → 财务稳定性优秀
±15%-30%    → 中性观察
> ±30%      → 盈利稳定性差，大幅扣分

拆分波动来源：原材料/费用/产能利用率/非经常性损益，哪一项导致？
```

**D3. NonRec% 规范化校验**

**对齐 [0] NonRec% 前置校验规则。** 此处仅确认：

```
< 10%      → 盈利质量干净，加分
10%-30%    → 需备注一次性收益来源，谨慎看待当期利润
> 30%      → 全部改用扣非净利润核算 PE、ROE
> 80%      → 直接淘汰
```

**D4. ROE 门槛 + 杜邦拆解**

```
基础门槛：
  近 3 年年化 ROE 中枢 ≥ 20% → 优质
  近 3 年中枢 < 10%          → 直接扣分

杜邦三因子拆解（必须写清）：
  高 ROE = 高净利率（产品壁垒）? / 高周转率（商业模式优秀）? / 高杠杆（负债扩张）?

高杠杆驱动的 ROE → 结合资产负债率做风险扣减，不算优质财务指标。
```

**D4 补充 — 重资产扩张期企业的 ROE 容忍度（v1.5.3）:**

IDC/电网/设备等重资产行业在 capex 扩张高峰期，ROE 会因资产快速膨胀而暂时压制。这不是基本面恶化，是会计滞后——新产能投产后 ROE 才会回升。

```
ROE < 10% + 行业为重资产（IDC/电网/设备）:
  → 不自动淘汰，但触发联合审查

联合审查规则（三条全部触发 → 淘汰）:
  ① ROE < 5%（年化）
  ② PE(TTM) > 40x
  ③ 营收增速 > 20% 但 ROE 不升反降 → 经典"增收不增利"陷阱

  案例（2026.7.3 奥飞数据）: ROE 3.7% + PE 55x + 营收加速但 ROE 连年低位
  → 三条全触发 → C 级淘汰。高增长不能为低回报辩护。

通过联合审查的（如 ROE 6-10% + PE < 30x + 产能投产在即）→ 纳入观察，等待 ROE 拐点确认。
```

**隐含财务校验（对齐前序步骤）：**

```
经营现金流/净利润连续多年 > 1 → 利润含金量高（对齐 [2] FCF）
商誉/净资产 > 30%            → 标记减值风险，财务质量降级（对齐 [0]）

CFO/NP < 0.5 连续两季 → 不自动淘汰，按商业模式审查（v1.5.4新增）：
  以下三类豁免：
  ① 产能扩张期：固定资产/总资产 > 30% 且 在建工程 YoY > 50% → 豁免
  ② 战略性备货：存货/总资产 > 40% 且 存货YoY > 营收YoY → 豁免
  ③ 项目型确认：合同负债 YoY > 50% → 利润集中度豁免（Q4集中确认）
  不属于以上三类 → CFO/NP < 0.5 连续两季 → 标记"利润含金量不足"，降一级
```

### Step E - 周期位置（四类周期判定 + 估值使用强制规则）

**E1. 四类周期判定依据**

```
强周期：盈利高度依赖大宗商品价格/上游能源供需/下游资本开支波动
        （煤炭/有色/化工/钢铁/电力/电力设备），利润波动极大

中周期：盈利跟随行业产能扩张和政策周期，但波动小于大宗商品
        （汽车/通用机械/半导体设备）

弱周期：盈利受宏观经济周期影响较小，需求弹性高
        （医药/必选消费品）

非周期（成长弱周期）：需求由技术替代/渗透率提升驱动，受宏观波动影响有限
        （软件/AI/创新消费）
```

**E2. 不同周期下的估值强制规则（v1.5.4 更新）**

```
强周期：
  禁止用低 PE 作为投资理由。行业盈利巅峰往往对应最低 PE——经典 PE 陷阱。
  估值优先使用 PB 历史分位、PS 分位，结合行业产能供需判断当前所处阶段
  （复苏/繁荣/衰退/萧条）。

  强周期 + PE<15 → 不自动淘汰，触发二次审查（v1.5.4新增）：
    审查① 利润是否还在加速？（QoQ增速 > 前两季均值）
    审查② 行业供给是否仍在收缩？（行业资本开支YoY < 0）
    审查③ PB分位是否 < 30%？
    三项全满足 → 周期底部复苏，不淘汰
    任一项不满足 → 周期顶部PE陷阱，淘汰

  注：PE=15为估计阈值，回测验证见 references/pe15-backtest.md。
  PB分位计算方法见 references/pb-percentile-method.md。

中周期：
  PE 作为辅助参考，需根据未来预期盈利变化调整，不能单纯依赖历史 PE 分位。
  使用 PEG 和 PB 交叉验证。

弱周期/非周期成长行业：
  PE 陷阱效应可忽略，使用 PEG + 历史 PE 分位估值。
  PEG ≤ 1 具备安全边际，高 PEG 必须有高增长和高壁垒支撑。

  非周期品低PE注意（v1.5.4新增）：
  PE<15 且 营收增速<5% → 价值陷阱（低增长低估值无限横盘），淘汰
  （PEG数学: PE=15/增速5%=PEG=3.0 > 框架PEG≤1.0标准）
```

**E3. 与 Step C 增长动量交叉验证**

```
周期下行阶段 → 即使短期增速快，估值预期和仓位需同步下调。
周期上行 + 公司加速 → 正常执行。
```

**E4. 市场分类错误识别（v1.5.1 新增）**

A股市场常见"分类错误"导致的折价或溢价，识破后是核心阿尔法来源：

```
错误分类类型：

① 周期股被误判为成长股（PE陷阱正向）
  例：半导体设备PE 100x+ → 市场当成"AI成长"定价，实际产能周期即将过剩

② 成长股被误判为周期股（PE陷阱反向）
  例：时代电气 19x PE → 市场按"轨交周期股"定价，但43%新兴装备(IGBT/SiC/电驱)被忽视
  判定方法：SOTP分部估值 — 若分部合计 > 当前市值 30%+ → 分类错误折价存在

③ 重资产被误判为轻资产（PEG陷阱）
  例：IDC公司 → 市场只看净利润PEG<1很便宜，不看FCF PEG(重资产需以FCF PEG为准)
  判定方法：对比净利润PEG和FCF PEG — 若净利润PEG<1但FCF PEG>3 → 估值陷阱

④ REIT/资产处置收益造成的PE虚低
  例：IDC/基建公司通过REIT处置产生一次性收益 → 归母PE很低但扣非PE极高
  判定方法：强制使用扣非PE，NonRec>30%自动切换

分类错误纠正需要催化剂（季报数据/事件驱动/券商SOTP研报），
在纠正前可能长期维持错误定价 → 仓位控制是唯一的保护。

**⑥ Q2预告PE骤降陷阱（v1.5.4）:**\n\n强周期股发布炸裂的Q2/H1预告后，TTM PE会因利润暴增而骤降（如48x→21x）。这是PE陷阱最危险的变体——\"PE只有21x了，很便宜！\"的叙事会诱使投资者忽略周期本质。\n\n```\n判定方法:\n  Q2预告发布后PE骤降 ≥ 40%（如48x→21x）\n  + 公司为强周期股（Step E 判定）\n  + CFO/净利润 < 0.5 或 FCF为负\n  → PE骤降是利润周期性冲顶的滞后反映，非估值修复\n  → 强制使用PB/PS分位估值，禁用PE\n\n  案例: 江波龙(301308) 2026.7.3发布H1预告(归母92-110亿)\n       → TTM PE从48x骤降至21x，表象\"变便宜了\"\n       → 实际: 180亿存货/GPM 55.5%处于周期顶部/CFO/NP=-0.74\n       → 高管40亿+减持印证产业资本判断\n       → Q2环比增速(+38-84%)已较Q1(+444% QoQ)明显减速\n       → 21x PE是周期顶部利润制造的\"伪安全边际\"\n       \n  防御: 预告后PE骤降的强周期股，必须等Q3/Q4数据确认利润可持续性\n         若Q3环比增速继续放缓至个位数 → 周期顶部确认，PE将跳升至100x+\n```\n\n**⑤ 营收加速 + ROE停滞 = 增长陷阱（v1.5.3）:**

A股常见叙事：\"营收高增→迟早利润会跟上\"。但大量重资产行业中这恰恰是反向指标——营收增长靠capex堆出来，ROE反而因资产膨胀被压制，形成\"越增长越不赚钱\"的恶性循环。

```
判定方法:
  营收增速 > 20% + 近3年ROE不升反降（或持续<5%）
  + PE > 40x → 直接淘汰，不等\"利润拐点\"

  案例: 奥飞数据(300738) 2026Q1 营收+31.1%加速 / ROE 2023=5.2%,2024=3.9%,2025=3.7%连降
       → 市场按AI成长股定价(PE 55x)，实际ROE < 劣质债券
       → C级淘汰
       
  对照（若存活）: 营收增速 > 20% + ROE从3%→8%拐头 + PE < 30x 
       → \"拐点型\"，列入观察等待确认

### Step G - 风险（单最大风险 + 概率×损失量化 + 风控约束）

**G1. 核心风险方向（限定范围，避免空泛列举）**

```
上游原材料价格暴涨 / 汇率大幅波动 / 行业价格战加剧 /
下游资本开支削减 / 新技术替代 / 大客户流失 /
行业严监管 / 产能过剩
```

**G2. 标准化写作模板（强制三要素）**

```
① 单最大风险：只列一个最致命的风险
② 发生概率：低(0-30%) / 中(30%-60%) / 高(60%-100%)
③ 损失幅度：风险兑现后，归母净利润下滑幅度 < 15% / 15%-30% / > 30%
```

**G3. 风险分级对应风控约束**

```
高概率 + 下滑 > 30%    → 致命风险，仓位上限强制降至观察仓（≤10%）
中概率 + 下滑 15%-30%  → 常规重大风险，不可重仓
低概率 + 下滑 < 15%    → 温和风险，不影响基准仓位配置
```

**G4. 预警指标前置**

```
买入前必须想好该风险的观察预警指标。
例：原材料价格 / 下游开工率 / 行业产品报价
一旦指标触发预警 → 提前减仓规避，不等风险兑现。
```

## [7] 估值分析

### 三情景估值

```
保守（行业下行）：绑定具体假设——如"下游需求-10%、ASP降5%"
基准（当前景气延续）：绑定当前趋势外推
乐观（催化剂落地）：绑定 Step F 的可验证催化剂——如"SiC产线投产、首个AI客户订单"
```

不能拍脑袋给 PE。每种情景必须写明对应的业绩假设。

### PE 估值

- 当前 PE + FY2026E + FY2027E + PEG
- 与自身 5 年 PE 中位对比
- 与同赛道同行对比

### PEG 与资本开支联动（v1.3 新增）

```
净利润 PEG = PE(TTM) / NP增速(%)
FCF PEG    = PE(TTM) / FCF增速(%)

重资产行业（IDC/电网/设备/封测/IDM）：以 FCF PEG 为准
  净利润 PEG < 1.0 但 FCF PEG > 2.0 → 估值陷阱——利润增长靠借钱堆出来
轻资产行业：净利润 PEG 为准
```

### 绝对估值打底（v1.3 新增）

PE 比价不能作为唯一依据。周期性行业 PE 为负或极低时完全失效。

```
非周期品：DCF 绝对估值 → 与 PE 估值双向校验，差异 > 30% → 质疑假设
周期性行业（强/中周期）：以 PB/PS 历史分位为主、PE 为辅助
  PB 分位 < 30% → 估值偏低（周期底部区域加分）
  PB 分位 > 70% → 估值偏高（周期顶部区域减分）
```

## [8] 买点分析 & 交易规则

### 入场区间

- 买入区间（基于MA20/MA30技术位）
- 优先 TREND_START 信号（MA20刚拐头向上 + MA30走平）

### 三级仓位体系（v1.4 新增）

仓位与 Step 5 评级挂钩。评级越高，允许仓位越高。

```
A 级：基准仓 10-25%，重仓上限 35%
B+ 级：基准仓 8-20%，重仓上限 25%
B 级：观察仓 ≤10%，基准仓 5-15%
C 级：仅观察仓 ≤5%，禁止基准仓
D 级：不纳入
```

此为 L4 战略仓位建议。L5 实操仓位由 `a-share-trading-plan` 环境缩放调整，实操 ≤ 战略上限。

### 加仓双硬约束（v1.4 新增）

每笔加仓必须同时满足两条，缺一不可：

```
① 基本面逻辑未证伪
   Step F 催化剂仍在有效期内
   最近一期季报未出现"低于预期"偏差

② 技术面回踩关键支撑企稳
   MA20/MA30 缩量回踩确认（VP_LABEL=CORRECTION）
   或 TREND_START 信号重新触发
```

**绝对禁止浮亏加仓摊薄成本。** 底仓未盈利前不开加仓。底仓浮盈 > 10% 才能开进攻仓（继承 a-share-trading-plan Tier 2 逻辑）。

### 止损双重风控（v1.4 新增）

```
单笔个股绝对亏损止损：
  单只亏损 ≥ 8%（从入场价计算）→ 无条件减仓 50%
  单只亏损 ≥ 12%               → 无条件清仓
  触发后 3 个交易日内执行完毕，不拖延

技术形态止损：
  MA30 有效跌破（价在MA30以下 + MA30方向DOWN）
  → 触发双确认制 B 条件
```

两种止损是**互补关系**——技术形态未破但绝对亏损已达 8% → 框架可能看漏了，先减再说。8% 是硬保险，不等框架确认。

### 卖出条件

双确认制（继承 `a-share-trading-plan`）：
- A 条件：框架否定（赛道 score 降级/基本面恶化/Step F 催化剂失效）
- B 条件：技术破位（MA20/MA30 有效跌破，经量价验证）

8% 绝对止损优先于双确认制——触发 8% 无条件执行，不等待 A/B 条件确认。

## 数据铁律：记忆 ≠ 实时数据（v1.5.2 新增）

**背景：2026.7.2 金盘科技分析事故。** Agent 凭记忆声称金盘科技"最强趋势"，实为 MA20斜率-4.86%/MA30 DOWN/月跌17.7%/ATH-25.6%的 真DOWN。用户两度纠正："不要凭借记忆说话，数据的记忆真的会过时。""我昨天都告诉过你我的持仓。"

**铁律：**

```
记忆（SOUL.md / hindsight / 持久记忆）:
  → 只存框架规则、用户偏好、方法论、静态行业知识
  → 不可存股票价格、MA方向、持仓比例、PE、增速等时变数据

每次执行 [1]-[3] 步骤前:
  → 必须通过 API 实时拉取财务数据、K线、行情
  → 禁止从记忆调取任何"上次分析时"的价格/趋势/持仓数据

持仓引用规范:
  → 每次引用用户持仓前，先确认最新状态（SOUL.md最近更新日期 vs 用户最近发言）
  → SOUL.md 标注"用户确认"日期，超过3个交易日 → 主动询问确认
  → 用户口头告知的最新持仓优先于 SOUL.md 书面记录
```

**违规记录（不要再犯）：**
1. **2026.7.2 — 金盘科技**：凭旧记忆说"最强趋势"，实际技术面已全面破位。教训：任何关于价格/趋势/持仓的断言必须先拉K线。
2. **2026.7.2 — SOUL.md**：持仓列表落后于用户两次告知，直到第三次纠正才更新。教训：用户口头确认 > 书面记录。

## 与框架的关系

- `小齐股市框架` 的 Stage 6C 调用本 skill 作为子流程
