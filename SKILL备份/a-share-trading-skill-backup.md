> **做什么**: 看大环境，算总仓位上限。不淘汰任何标的。

## 0.1 L0 情绪温度计（W&W）

```
数据源: 步骤A — ww_indicator.py

W&W 读数    区间           压缩系数   含义
0-20       Very Bullish    ×1.2     极度恐惧，温和上浮（防止踏空）
20-40      Bullish         ×1.0     偏恐惧，不压缩
40-60      Neutral         ×1.0     中性，不干预
60-80      Bearish         ×0.6     偏亢奋，收一收
80-100     Very Bearish    ×0.4     极度亢奋，大幅收缩

底部设计: ×1.2而非×1.5 — A股底部是区域不是一根线，加一点不加满。
         回测支撑: 2011.9(20.7)、2019.1(32.2)、2024.9(29.8)三次大底皆在Bullish区。
```

## 0.2 L1 SP500 极端风险

```
数据源: 步骤B — compute_sp500_score.py
  读取 风控模型0415.xlsx，RV20替代VIX×1.2系数，z-score 364周滚动窗口
仅在全球危机时介入（L4地狱/L5炼狱）→ 一票否决，仓位强制 ≤ 35%/15%
日常不介入。
```

## 0.3 L2 宏观象限

```
数据源: 步骤E — CPI/PPI/PPIRM/PMI（国家统计局，月度） + Z-Credit/Z-Monetary（用户月度PDF）
  信用维度依赖用户PDF — akshare/East Money 无法替代。
  降级模式（用户PDF未更新时）:
    信用方向公开替代: 社融存量增速YoY + M1-M2剪刀差 + 企业中长期贷款YoY
    → 可判断信用"扩张/收缩"方向，不能算精确仓位上限
    → 标注"公开数据近似 — 精度降一级"，仓位上限取保守值: 50%

六象限 → 仓位上限 + 不碰方向:

宽信用扩张 / 信用修复型再通胀 / 低通胀稳增长 → 80%
紧信用放缓                                      → 55%
供给冲击型滞胀 / 通缩式下行                       → 50%

不碰方向: 成本敏感型中游制造业（PPI-PPIRM为负时）
  → 翻译为 L3 具体赛道黑名单 → PART 1 自动过滤
  豁免: GPM ≥ 30% 自动豁免（高毛利=定价权=成本传导能力）
        P6 [L1] 审问可推翻此豁免，需说明理由并记录在案
```

## 0.4 仓位天花板（汇总计算）

```
L5_仓位天花板 = L0_WW压缩 × L2_宏观上限 × 100%

IF L1 = L4(地狱) / L5(炼狱) → 天花板 = L1_硬帽子(35% / 15%)，覆盖上述公式
否则 → 日常公式生效

规则:
- 这是天花板，不是目标。找不到好标的 → 现金就是持仓
- 单票 ≤ 10%（天然上限，除非你明确说可以更高）
- 同族子赛道合计 ≤ 单票上限 × 1.2

现金底仓（强制最低现金比例，天花板之外的独立约束）:
  W&W > 80（极度亢奋）→ 现金 ≥ 30%
  W&W > 60（偏亢奋）   → 现金 ≥ 10%
  其余                   → 无强制
```

防线② — 价值陷阱:

    例外: 重资产行业(IDC/电网/设备) + ROE 6-10% → 观察豁免
    → PART 6 [G1] 审问

=== PEG旁路（纠正"成长被误判为高估"的分类错误）===

触发条件（三条全满足 → 不因PE超标淘汰，走PEG旁路）:

  通过 → 标记 [PE超标-PEG旁路]
  不通过 → 按正常PE超标处理，PART 6 [V3] 审问

  仅 A → 设止盈，不动手
  仅 B → 按强弱B分级减仓
  A+B 同时满足 → 执行减仓/清仓
