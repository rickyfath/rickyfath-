## 2. 角色 A: 产业周期择时

### 7 步流程

### Step 1: 6 个核心指标

两个独立链路 × 两种角色（决策 vs 资产）：

```
Lead（领先指标）— 企业当期主动决策
  ┌──────────────┬──────────────────────┬─────────────┐
  │ 指标          │ 含义                  │ 周期         │
  ├──────────────┼──────────────────────┼─────────────┤
  │ 合同负债 YoY  │ 客户预付订单款          │ 库存: 订单端  │
  │ 现金购买 YoY  │ 企业采购原材料付现       │ 库存: 采购端  │
  │ CAPEX YoY    │ 资本开支同比            │ 投资: 决策端  │
  └──────────────┴──────────────────────┴─────────────┘

Lag（滞后指标）— 已发生的资产沉淀
  ┌──────────────┬──────────────────────┬─────────────┐
  │ 指标          │ 含义                  │ 周期         │
  ├──────────────┼──────────────────────┼─────────────┤
  │ 存货 YoY      │ 资产负债表存货同比       │ 库存: 资产端  │
  │ 在建工程 YoY  │ 在建产能项目同比         │ 投资: 资产端  │
  │ 资产周转率(反) │ 产能利用效率            │ 投资: 效率端  │
  └──────────────┴──────────────────────┴─────────────┘
```

**关键时序**: Lead 领先 Lag 1-3 个季度。
合同负债(订单) → 现金购买(采购) → 存货(产品)
CAPEX(决策) → 在建工程 → 固定资产形成

---

### Step 2: z-score 标准化

```
z = (当前值 - 65季历史均值) / 历史标准差

方向统一: 资产周转率取z后翻负号
  → 高效 = 低位 = 底部
  → 6个指标方向一致: z越正 = 越近顶部, z越负 = 越近底部
```

---

### Step 3: Lead/Lag 合成 + 分歧

```python
Lead_z = mean(合同负债_z, 现金购买_z, CAPEX_z)
Lag_z  = mean(存货_z, 在建工程_z, 资产周转率_反向_z)
Divergence = Lead_z - Lag_z  # 分歧 = 周期相位计
```

**分歧是 L3 最核心的单一指标：**

| 分歧值 | 剪刀状态 | 周期相位 | 操作含义 |
|--------|---------|---------|---------|
| > +0.3 | 剪刀大开，Lead在上 | 复苏初期/反转早期 | **寻找买点** |
| ~0 | 剪刀闭合 | 全面过热或全面出清 | 持有或等待 |
| < -0.3 | 剪刀反开，Lag在上 | **顶部酝酿** | 减仓/设止盈 |

**2021 年顶部案例**:
- 21Q1: Lead +1.09, Lag +0.28, 分歧 +0.81 → 剪刀大开
- 21Q4: Lead +0.10, Lag +0.62, 分歧 **-0.52** → 剪刀反开，顶部已成
- 创业板随后 **-52%**

### Step 4: T1-T4 四层信号体系

| Tier | 名称 | 触发条件 | 历史次数 | 置信度 | 典型时机 |
|------|------|---------|---------|--------|---------|
| **T1** | 高置信底 | Lead_z < -1.0 AND Lag_z < -0.5 | 2次 | **极高** | 2024Q3, Q4 |
| **T2** | 拐点底 | 分歧从负转正 AND Lag_z < -0.2 | 3次 | 中高 | 2017Q1, 2018Q4, **25Q4** |
| **T3** | 拐点顶 | 分歧从正转负 AND Lag_z > +0.2 | 3次 | 中高 | 2010Q2, 2011Q2, 2021Q2 |
| **T4** | 高置信顶 | 分歧2季度差 < -0.8 AND Lag_z > 0 | 3次 | **极高** | 2010Q4, 2011Q3, 2021Q3 |

### 信号使用规则

```
1. T2/T3是预警，T1/T4是确认
   先看T2/T3拐点警报，再等T1/T4极端信号做最终确认

2. T2触发后可以开始寻找买点，但不等于立即买入
   结合MA20技术面确定具体入场时机

3. T3触发后收紧止盈至MA10，T4触发后清仓
   T3到T4之间通常1-2个季度，是减仓窗口

4. 单一信号不操作
   T2+T1连续触发 > 单独T2
   T3+T4连续触发 > 单独T3
```

### 历史验证（创业板）

| 信号 | 触发后表现 |
|------|-----------|
| 2018Q4 T2底 | 12月 +44%, 24月 +137%, 36月 +166% |
| 2024Q3/Q4 T1底 | 政策前夕 1580→3238 (+105%) |
| 2021Q3 T4顶 | 创业板 3576→1573 (-52%) |
| 2010Q4 T4顶 | 创业板 1138→607 (-47%) |

**T4 逃顶信号 100% 命中历史上的 3 次大顶，每次后续跌幅均超过 45%。**

### Step 5: 9-Bucket 斜率预期

Lead 和 Lag 各分 3 档（低/中/高），形成 9 个格子。每个格子对应不同的未来 6 月预期收益。

```
                Lag低       Lag中       Lag高
  Lead低        +37.4%       —           —        ← 最优
  Lead中          —          —           —
  Lead高          —          —         -13.7%     ← 最差
  
  行均值: Lead低 +38.7% | Lead中 +4.5% | Lead高 -3.8%
```

### 关键发现

1. **Lead 是主要方向决定因素**
   Lead低行均值 +38.7%，Lead高行 -3.8%，差 42pp——单调关系

2. **Lag 中位时收益最高（轻度 inverted-U）**
   出清后开始恢复、但未过热时最佳
   Lag低列 +14.5% vs Lag中列 +16.6%

3. **两个对角极端差 51pp**
   左下（Lead低×Lag低） +37.4% vs 右上（Lead高×Lag高） -13.7%

4. **样本独立性受限**
   左下cell的11个样本中9个来自2023-2025连续区间，仅作描述参考

### 使用规则

```
落在左下cell → 支持积极建仓（产业周期配合）
落在右下或右上 → 不支持新买入
Lag中位 > Lag低位 → 最优买点可能在Lag回升至中位时，非当下最低点
```

### Step 6: 三个增强信号

#### ① Δdiv(2Q) — 分歧变化速度

分歧的绝对值是静态快照。**2 季度变化量揭示反转"冲量"**：

```
2018Q4 T2底: Δdiv = +0.68 → 36月 +166%  (强力反转)
2025Q4 T2底: Δdiv = +0.11 → 待验证        (微弱反转)

同样是T2触发，反转动能差6倍。
```

**操作规则**:

| Δdiv(2Q) | 反转强度 | 操作 |
|-----------|---------|------|
| > +0.5 | 强力反转 | 积极建仓 |
| +0.2 ~ +0.5 | 中等反转 | 半仓试探 |
| < +0.2 | 弱反转 | 最小仓位或等待 |

当前 26Q1: Δdiv ≈ +0.18 → 弱反转，等 Q2 确认。

---

#### ② Lead 内部分化 — "采购起、订单弱"

三个 Lead 指标并非总是同步。26Q1 出现典型分化：

| Lead 指标 | 26Q1 z | 变化 | 信号 |
|-----------|--------|------|------|
| 现金购买 YoY | -0.14 | **+1.31 ↑↑** | 采购大幅回升 |
| CAPEX YoY | -0.04 | +0.13 ↑ | 回到均值 |
| 合同负债 YoY | **-1.44** | **-0.72 ↓↓** | 订单端恶化 |

**铁律**: 当三个 Lead 指标方向不一致时，**合同负债（订单端）是最终确认指标**。
现金购买回升 + 合同负债仍弱 = 等订单确认，不急于重仓。

历史上"采购起、订单弱"有两种演化路径：
- 有政策刺激（2020Q2）：订单 2-3 季度后跟上 → 确认反转
- 无政策推动（当前）：订单能否自然跟上 **未验证**

**触发条件**: 合同负债 z 连续 2 季度回升 → 内部分化解除 → T2 强度升级。

---

#### ③ Lag 中位最优

当前 Lag_z = -0.67（低位），距中位区间（-0.3 ~ 0）还有距离。

**最优买点可能不在"现在赶紧买"，而在 Lag 回到中位、确认恢复但未过热时。** 不因"现在在 Lead低×Lag低最优cell"而急于满仓。

### Step 7: CF40 需求拆解（互补视角）

6 指标从企业微观看"周期在哪"，CF40 从宏观需求看"为什么在这"。

**指标**: 实际固定资产周转率 = 剔除价格因素的营收 / 固定资产净值
→ 产能利用率近似指标，领先 PPI 约 1 年

**五类需求来源** (2011-2025 均值):

| 需求来源 | 占比 | 性质 | 当前状态 |
|---------|:---:|------|---------|
| **出口** | 32-35% | 外需、外生 | **+14.3% — 本轮最强** |
| 制造业投资 | 15-17% | 内需、内生反馈 | +3.3% — 缓慢恢复 |
| 消费 | 22-26% | 内需、外生 | +6.4% — 缓慢 |
| 基建 | 12-15% | 内需、外生 | 财政驱动 |
| 房地产 | 3.5-6.8% | 内需、外生 | -3.6% — 持续收缩 |

**复苏顺次**: 外需(出口) → 制造业投资 → 纯内需(消费/房地产/基建)

**和 L3 6 指标体系的结合**:

```
T2触发 + 分歧>0 + 外需拉动   = 强确认 (出口驱动，有持续力)
T2触发 + 分歧>0 + 仅内需     = 弱确认 (缺乏外需接力，修复更慢)
T3触发 + 出口走弱            = 周期顶部可信度高
```

**2015-2016 vs 2024-2025 关键对比**:

| 维度 | 2015-2016 | 2024-2025 |
|------|-----------|-----------|
| 出口 | -0.2% → 8.5% | 9.8% → 14.3% |
| 房地产 | 0.6% → **25.0%** | -6.1% → -3.6% |
| 回升结构 | **全面向好，动能多元** | **仅出口单边支撑** |

**K 型复苏**: 外需较强、内需偏缓。本轮修复比 2015-2016 更平更缓。

## 4. 与 MA20 技术面的配合

L3 定"该不该买"，MA20 定"买在哪儿"。两者一致时才行动。

| L3 信号 | MA20 状态 | 操作 |
|---------|----------|------|
| T2触发 + 分歧>0 | MA20刚拐头向上 + 缩量 | **最佳买点** |
| T2触发 + 分歧>0 | MA20已上行 + 偏离>10% | 等回调 |
| T3触发 + 分歧<0 | MA20上行 + 偏离<5% | 收紧止盈至 MA10 |
| T4触发 | MA20拐头下行 | **清仓** |
| 无信号 | MA20上行 | 正常持有 |

**铁律: L3 的方向判断优先于 MA20 的位置判断。两者打架时，信 L3。**

## 5. 对 L4 个股的应用

框架核心是通用的。对单只股票或子板块：

```
1. 取该板块/个股的6指标财务数据 (East Money datacenter)
2. 计算65季历史z-score (或使用行业均值作代理)
3. 合成 Lead/Lag/分歧
4. 对照 T1-T4 信号阈值 (个股噪声大，阈值作参考)
5. 定位 9-Bucket 位置
```

**注意**: 个股 6 指标噪声远大于指数。对个股优先用**创业板整体信号**判断大方向，然后结合 L4 z-score 和 MA20 确定具体标的。

### 数据源

| 数据 | 来源 | 频率 | 状态 |
|------|------|------|------|
| 6 指标 (合同负债/CAPEX等) | East Money 财务 API | 季度 | △ 可用, 个股噪声大 |
| T1-T4 信号 | 创业板整体 (代理) | 季度 | ✓ 已有历史数据 |

### 已知限制

1. **季度频率**: 无法捕捉月内变化
2. **Domain 边界**: 估值/流动性/突发事件主导时段（2015 杠杆牛、2018 贸易战）会失灵
3. **个股噪声大**: 6 指标在个股层面波动远大于指数
4. **样本有限**: 65 个季度，11 次信号触发。统计显著性受限
5. **9-Bucket 独立性**: 左下cell的11个样本中9个来自2023-2025连续区间
6. **不预测政策**: 突发政策可能导致产业周期信号被覆盖
7. **角色 B 已建**: 5511只BK黑名单, Stage 2.0自动生效
