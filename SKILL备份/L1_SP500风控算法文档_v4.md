## 1. L1 是干什么的

**一句话：紧急刹车，不是日常温度计。只在极端风险时介入。**

L1 的所有数据来自美国市场——SP500、VIX/RV20、HY OAS、10Y-2Y。它测量的是"美国市场有多危险"。

但美国市场 ≠ A 股市场。两者在三个场景下的关系：

| 场景 | 美国 | A 股 | 有因果链？ | L1 应该 |
|------|------|------|-----------|--------|
| 全球危机(2008/2020) | SP500 暴跌 | A 股暴跌 | ✅ 有 | 介入 — 硬帽子 |
| A 股独涨(现在) | SP500 平稳 | A 股亢奋 | ❌ 无关 | 不介入 |
| A 股独跌 | SP500 平稳 | A 股崩盘 | ❌ 无关 | 不介入 |

**L1 只在场景 1 有因果链——全球危机→外资撤→A 股跟跌。** 场景 2/3 里，SP500 数据对 A 股仓位没有信息量。

### 在框架中的位置（v4.1 修正）

```
日常:
  L0 (A股情绪刹车) → 压缩系数(×0.4/0.6/1.0)
  L5 = min(L4_战略, L0_WW × 100%)           ← L1 不参与日常乘法链

极端:
  L1 = L4(地狱)或L5(炼狱)时 → 硬帽子 35%/15%
  L5 = min(L4_战略, L1_硬帽子)               ← L1 行使一票否决

设计原则:
  L1 回归它的本来角色——否决权。平时不管，极端时一票否决。
  SP500 模型判断 A 股的日常仓位没有因果依据。
  A 股日常仓位由 L0(本土情绪) + L4(选股质量) 决定。
```

## 4. Step 2: 5 特征 z-score 计算

### v4 统一窗口: 364 周（7 年）滚动

```
z_i = (X_i - μ_364w) / σ_364w

μ_364w: 过去364周的均值
σ_364w: 过去364周的标准差

z > 0 = 比过去7年平均更危险
z < 0 = 比过去7年平均更安全
```

**v3→v4 变更**: 原来用扩展窗口（2000年起），2008 年极端值永久扭曲均值。v4 统一为 364 周滚动，和百分位用同一窗口，2008 在 2015 年后自动过期。

### 5 个特征

| # | 特征 | 权重 | 数据 | 方向 | z > 2 含义 |
|---|------|------|------|------|-----------|
| 1 | **RV20_z** | 25% | SP500 4周实际波动率 (年化) | RV↑→风险↑ | 波动率暴冲 |
| 2 | **HY变化_z** | 25% | HY OAS 13周变化 | 利差↑→风险↑ | 信用危机 |
| 3 | **期限利差反转_z** | 15% | 10Y-2Y 利差 | 利差↓→风险↑ | 收益率倒挂 |
| 4 | **标普趋势_z** | 15% | SP500 vs MA40 偏离 | 价格↓MA→风险↑ | 趋势破位 |
| 5 | **MA斜率_z** | 20% | MA40 8周斜率 | 斜率↓→风险↑ | 均线下行 |

---

## 5. Step 3: 否决权检查

```python
IF any(z > 2.0 for z in [RV20_z, HY_z, Spr_z, SP_z, MA_z]):
    → 直接拉到 L5 (炼狱), Score = 3.0
    → 仓位上限 = 15%
    → 不管其他特征多好

IF Sahm_z > 2.0:
    → 额外触发否决权
```

否决权是 L1 的最后防线——即使综合 Score 还好，只要单一特征暴冲，直接锁仓。

---

## 6. Step 4: 加权合成 Score

```python
Score = RV20_z × 0.25
      + HY变化_z × 0.25
      + 期限利差反转_z × 0.15
      + 标普趋势_z × 0.15
      + MA斜率_z × 0.20

若否决权触发: Score = 3.0 (强制炼狱)

Score > 0 = 比历史平均危险
Score < 0 = 比历史平均安全
```

若某个特征不可用（如 Spr_z = NaN），跳过该特征并重归一化剩余权重。

---

## 7. Step 5: 364 周滚动百分位

```python
历史Score序列 = Excel '评分与状态_周度' 最后364周
百分位 = (历史Score ≤ 当前Score的个数) / 364 × 100

百分位越低 = 当前风险在历史中越低 = 可以多配
百分位越高 = 当前风险在历史中越高 = 必须减仓
```

**已知限制**: 百分位对比的是 Excel 旧版（v3 扩展窗口）Score 历史，v4 的滚动窗口 Score 与 v3 的扩展窗口 Score 分布不完全可比。全量重算需要重建 Excel。目前标注为"估计值"。

## 8. Step 6: 6 级状态映射 → 仓位上限

| 百分位 | 等级 | 标签 | 仓位上限 | 介入 L5? | 含义 |
|--------|------|------|---------|----------|------|
| 0-20% | L0 | 简单 | 100% | 不介入 | 一切正常 |
| 20-40% | L1 | 普通 | 85% | 不介入 | 轻微压力 |
| 40-55% | L2 | 困难 | 70% | 不介入 | 需要警惕 |
| 55-70% | L3 | 噩梦 | 50% | 不介入 | 显著风险 |
| 70-85% | L4 | 地狱 | 35% | **介入 — 硬帽子 35%** | 严重风险 |
| 85-100% | L5 | 炼狱 | 15% | **介入 — 硬帽子 15%** | 极端风险 |

**关键变更 (v4.1)**: L0-L3 不再参与 L5 仓位公式的日常乘法链。仅 L4/L5 以硬帽子形式介入。
L4/L5 的硬帽子和 Step 3 否决权逻辑自洽——否决权直接拉到 L5 15%。

## 9. Step 7: L1 条件介入 → L5 实操帽子

> **v4.1 核心修正**: L1 从日常乘法链退出，改为条件介入。

### 传导逻辑

```
IF L1_等级 == L4(地狱) OR L5(炼狱):           // 全球危机场景 — 有因果链
    L5_实操帽子 = L1_硬帽子(35%或15%)          // L1 行使一票否决
    // L0 不叠加 — 危机场景不需要情绪温度计确认
    
ELSE:                                         // 日常场景 — SP500数据不判断A股仓位
    L5_实操帽子 = L0_WW压缩 × 100%             // L1 不参与
    // A股仓位由L0(本土情绪) + L4(选股质量)决定
```

### 为什么这样改

```
场景 1 — 全球危机 (L1=L5):
  L1 硬帽子 15% — 有因果链（美国崩→全球崩→A股崩）
  不需要 L0 确认 — 2008/2020已经验证了这个因果链

场景 2 — A股独涨 (当前: L1=L3, W&W=90.3):
  原来: 70% × 0.4 = 28% — L1的70%是噪音（SP500平稳证明不了A股安全）
  改后: 0.4 × 100% = 40% — 只看L0本土情绪

场景 3 — A股独跌 (L1=L2, W&W=30):
  原来: 70% × 1.0 = 70% — L1给70%帽子但A股在崩，帽子太松
  改后: 1.0 × 100% = 100% — L1不介入，仓位由L4选股质量决定
```

### 当前示例 (2026.7.5)

```
L1等级 = L3(困难) → 不介入
L0_WW = ×0.4 (W&W=90.3 Very Bearish)

L5_实操帽子 = 0.4 × 100% = 40%
// 对比旧公式: 0.4 × 70% = 28%
// 差异12pp = 原来L1的"噪音税"
```

## 10. v4 三项升级 (2026.7.5)

### 10.1 升级 1: VIX → RV20 替代（解决最大单点故障）

**问题**: VIX 从中国 IP 无可用免费数据源。Yahoo/CBOE/Finviz/MarketWatch 全部 403。25% 权重依赖人工截图更新 Excel——这是"整层会不会失效"的问题。

**方案**: 用 SP500 20 日实际波动率（Realized Volatility）替代 VIX 空缺期。

```
RV20 = std(4周SP500周度收益率) × √52  (年化)
RV20_z = (RV20 - μ_364w) / σ_364w      (7年滚动z-score)
RV20_z_safe = RV20_z × 1.2              (安全系数)
```

| 属性 | VIX | RV20 |
|------|-----|------|
| 类型 | 隐含波动率（前视） | 实际波动率（后视） |
| 相关性 | 1.00 | ~0.85 |
| 转折点响应 | 即时 | 滞后 1-2 周 |
| 覆盖 | 尾部风险定价 | 纯统计 |
| 数据源 | [NO] | Sina SP500 日线 (可用) |

**×1.2 安全系数**: RV20 是后视镜，在暴跌刚开始时空波动率很低（还没反映到 20 日窗口里），但真实风险已在积累。×1.2 补偿这种滞后偏差。

**局限性**: 
- 平稳市场：RV20 ≈ VIX，替代效果最好
- 急跌转折：RV20 低估风险 1-2 周，×1.2 部分补偿但不完美
- 尾部事件：VIX 包含的"崩盘保险溢价"RV20 无法捕捉

### 10.2 升级 2: 统一到 364 周滚动窗口

**问题**: v3 的 z-score 用扩展窗口（2000年起，26年），百分位用 364 周（7年）。两个尺度不一致：
- z-score 被 2008 年极端值拉高均值 → 当前 z 看起来"还好"
- 百分位只看 7 年 → 不包含 2008 → 极端值消失

**方案**: 全部统一到 364 周滚动。

| | v3 | v4 | 影响 |
|---|---|---|---|
| z-score 窗口 | 扩展(2000起) | 364周滚动 | 2008 在 2015 年后不再影响均值 |
| 百分位窗口 | 364周 | 364周(不变) | — |
| 一致性 | 不一致 | **统一** | z 和百分位说同一种语言 |

### 10.3 升级 3: 流向 L0→L1（非 L1→L0）

**修正**: 公式数学上等价（乘法交换律），但逻辑流向是 L0 先刹车，L1 再出全球风控数字。输出模板改为 L0 先显示。

## 11. 4 个诊断陷阱

| 陷阱 | 症状 | 为什么骗人 | 防御 |
|------|------|-----------|------|
| **陷阱1: 缩量暴涨** | SP500涨但成交量缩 | SP_z+MA_z改善(35%权重)→Score假降→仓位假打开 | 降级时检查量能，缩量不执行加仓 |
| **陷阱2: 油价→VIX滞后** | 油价涨2-4周后VIX才暴 | 滞后期内"一切正常" | 盯油价+商品，当作VIX的领先指标 |
| **陷阱3: 利差歧义** | 10Y涨但分不清是增长还是通胀 | 增长→利好，通胀→危险 | 同时看油价+VIX：油价涨+VIX涨=通胀场景 |
| **陷阱4: 估值驱动vs盈利驱动** | SP500涨但EPS没跟上 | 价格涨→特征改善（虚假），EPS下调→快速回撤 | 计算价格涨幅-EPS涨幅，>5pp→降级打7折 |

## 12. L1 对 A 股的适用边界

```
适用场景:
  VIX暴冲(>30) → 全球恐慌 → A股外资撤 → 跟L1减仓 ✓
  模型在炼狱L5 → 全球危机 → 保守是对的 ✓

不适用场景:
  模型在地狱但SP500温和涨 → 不因此压缩A股仓位 ✗
  A股独走逻辑(军工/电力/国产替代) → L2六象限比L1重要 ✗
  美股涨A股跌 / 美股跌A股涨 → 方向相反时L1无效 ✗

铁律: L1输出"全球风险温度", L2输出"A股宏观方向"。
     两者打架时, A股仓位跟L2, L1只在极端风险时行使否决权。
```
