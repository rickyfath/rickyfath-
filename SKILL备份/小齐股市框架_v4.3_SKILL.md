## Stage 3.5: 周期股强制拦截（v4.3 新增）

**位置：PE筛选（Stage 3）之后、7步法（Stage 6C）之前。**

核心问题：8月Q2财报批量更新后，周期顶部暴利 → TTM PE被动下降 → 触发PE≤23买入门槛 → 框架把周期顶部的低PE股当成价值股买入。

### 拦截规则

```
凡Stage E判定为"强周期"或"中周期"的标的：
  ＞ 禁止使用绝对PE估值
  ＞ 改用历史PB分位 + PS分位判断估值位置
  ＞ "强周期 + PE<15" → 不自动淘汰，触发二次审查：
      审查① 利润是否还在加速？（QoQ增速 > 前两季均值）
      审查② 行业供给是否仍在收缩？（行业资本开支YoY < 0）
      审查③ PB分位是否 < 30%？（运行 `python3 ~/AppData/Local/hermes/scripts/pb_percentile.py CODE` 获取5年PB分位）
      三项全满足 → 周期底部复苏，不淘汰
      任一项不满足 → 周期顶部PE陷阱，淘汰
```

非周期行业的低PE规则：
```
"PE<15 且 营收增速<5%" → 价值陷阱（低增长低估值无限横盘），淘汰
（PEG数学: PE=15/增速5%=PEG=3.0，远超框架PEG≤1.0标准）
```

### PE=15阈值说明

PE=15为估计阈值（从PE=8陷阱下界与PE=23框架上限之间取中间值），待回测校准。当前优先级：**防止漏判（PE陷阱）> 防止误判（错杀周期底）。**

### CFO/NP豁免规则（按商业模式调整）

CFO/NP<0.5不自动淘汰，以下三类豁免：
1. **产能扩张期**：固定资产/总资产>30% 且 在建工程YoY>50% → 豁免
2. **战略性备货**：存货/总资产>40% 且 存货YoY>营收YoY → 豁免
3. **项目型确认**：合同负债YoY>50% → 利润集中度豁免（Q4集中确认导致Q2占比异常）

### 适用范围边界

- **适用**：存储、化工、煤炭、有色、新能源上游、船舶、养殖等强周期行业
- **不适用**：消费、医药、公用事业、必选消费品（盈利增速稳定、PE低+ROE高是常态而非陷阱）

对每只 Stage 5 幸存者执行。**从 v4.2 起，Stage 6C 不再内联 7 步法内容，改为调用独立 skill `finance/7-step-thesis`（当前版本 v1.5.4）。**

**注意：Stage 3.5 的周期股强制拦截在 Stage 6C 之前执行。强周期标的跳过绝对PE估值，直接使用 PB/PS 分位进入 7 步法。**

### [0] NonRec% Pre-Check 前置校验（框架级，MANDATORY FIRST — 本 skill 负责）

**原规则：**
- 扣非/归母 < 70% → 通过
- NonRec > 30% → 所有PE/ROE必须用扣非
- NonRec > 80% → 直接淘汰

**NonRec% 计算公式：**
NonRec% = 非经常性损益 ÷ |归母净利润|
使用绝对值分母，避免亏损股负净利导致统计口径混乱。

**前置排雷（与本步骤同级，不后置）：**

**(1) 商誉/净资产 > 30%**
- 仓位上限自动降一级：A→B+，B+→B，B→C
- 商誉/净资产 > 30% + 审计意见非标 → 直接淘汰（联合触发）

**(2) 资产负债率红线**
使用有息负债/净资产（非总负债率），避免经营性负债误杀。

| 行业类型 | 红线 | 触发动作 |
|----------|------|----------|
| 制造业/周期股 | 有息负债/净资产 > 70% | 标记高风险 |
| 消费类 | 有息负债/净资产 > 60% | 标记高风险 |

CFO/净利 < 0.5 连续两季 + 红线触发 → 直接进入观察池，禁止重仓。
行业豁免：重资产运营（IDC/电网/机场/高速公路）且 CFO/净利 > 1 → 豁免至 80%。

**(3) 暴雷引用：**
- 大股东质押率 > 50% → 标记，Lazy-Check 注明
- 审计意见非标 → 直接淘汰

## 捷径诱惑 — 反作弊规则（v4.2.1 新增，Iron Rule 0）

Agent在处理择股任务时存在反复出现的**捷径模式**：

```
错误: 手动挑知名股票 → 拉Q1+MA20 → 主观给评级 → 声称"走完了"
正确: BK板块提取全量成分股 → 逐Stage输出确认数据 → Stage 0-5淘汰完再谈评级
```

**强制防作弊：**
- 每次Stage输出必须包含具体数字（进入/淘汰数/通过率%）
- 禁止"我先快速扫一眼"——只有完整扫和不扫
- Stage 0-5期间禁止出现A/B/C/D评级（Iron Rule 4）
- 最终结论必须有"403→49→32→4→1→0"式漏斗数字链
- 没有BK代码提取全量成分股 = 等于没扫

**违规记录（7次）：**
1. 2026.6.3 — PE陷阱跳过周期判定
2. 2026.6.6 — SP500数据不验证
3. 2026.6.24 — 新雷能不拉K线就说"在MA20上方"
4. 2026.6.25 — 三次图快给错结论
5. 2026.7.2 — 金盘科技凭记忆说"最强趋势"实为真DOWN
6. 2026.7.2 — 持仓不确认直接引用SOUL.md
7. **2026.7.3 — 13只股5分钟自称"走完7步法"，被用户当场抓住跳Stage**

## Iron Rules

0. **禁止捷径。** 无快速扫。每Stage输出确认数据。
1. Every stock gets scanned. No representative sampling.
2. Monthly K-line BEFORE daily MA20.
3. Sub-sector decomposition BEFORE grading.
4. Stages 3-5 are elimination only — NO grades before Stage 6.
5. Q1报告分数决定择股范围 — 禁止主观选行业。
6. 概念关联度过滤在拉K线之前。
7. 生命周期标签差异化阈值，不是装饰性标签。
8. 元数据标签（MULTI_TRACK + CHAIN_POSITION）一次性标注、全局复用。
9. 关键词打分不能替代人工精判。
10. 量价配合是趋势的呼吸。
11. 估值贡献度不可用于强周期品。强周期 + PE<15 → 触发二次审查（利润加速+供给收缩+PB分位<30%），不自动淘汰。
12. 放量回调不是买点。
13. 纸上富贵不是钱。CFO/净利 < 0.5 连续两季 → 淘汰，但产能扩张/战略性备货/项目型确认三类豁免。
14. 低PE不是便宜。强周期品禁止用绝对PE估值，改用PB/PS分位。消费/医药/公用事业的低PE是常态而非陷阱。
PE<15 且 营收增速<5% → 价值陷阱，淘汰。
15. 行业好 ≠ 公司好。计算公司级 z-score 并与行业对比。
16. 伪分散化是真集中。同族子赛道总仓位上限 = MAX(各上限) × 1.2。
17. 选出来买不进去等于白选。日均成交额 < 3000万 → max仓位 2%。
18. 观察清单不是安慰奖。每只必须附带明确触发条件。
19. Lazy-Check 是强制输出。不可总结不可跳过。
20. 清理临时文件。桌面不得残留工作文件。
21. BK代码不验证直接提取成分股 → 致命。
22. 跳Stage导致赛道归属错误 → 致命。不跳任何Stage。
23. 加载skill后逐Stage执行，Stage Execution Checklist逐项打勾，跳一步标注原因并让用户确认。
