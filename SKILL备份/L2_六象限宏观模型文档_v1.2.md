## 1. L2 是干什么的

**一句话：判断中国经济处于什么状态，输出仓位上限 + "不碰什么"。**

L2 的所有数据来自中国——CPI、PPI、社融、PMI、M1/M2、信用脉冲。它测的是**"中国经济冷不冷、胀不胀"**。

核心原则：

```
否定判断（不碰什么） > 肯定判断（该买什么）
```

在框架中的位置：

```
L0  (A股情绪)     → ×0.4 刹车
L1  (SP500风控)   → 不介入 (L3困难)
L2  (中国宏观)     → 50%帽子 + 不碰清单
L3  (产业翻译)     → [空缺]
L4  (选股)        → 7步法
L5  (交易)        → min(L4战略, L2_L0定量帽子) + 不碰约束
```

## 3. Step 1: 四维数据采集（20+个指标）

### 维度 1: 价格（6个指标）

| 指标 | 频率 | 含义 | 来源 |
|------|------|------|------|
| **核心CPI（主）** | 月度 | 剔除食品能源，真实供需温度计 | 统计局 |
| 标题CPI（辅） | 月度 | 含食品能源，受猪周期干扰 | 统计局 |
| PPI | 月度 | 工业品出厂价，上游价格压力 | 统计局 |
| PPIRM | 月度 | 工业购进价，企业买入成本 | 统计局 |
| **PPI-PPIRM差值** | 月度 | 中下游利润空间 | 计算 |
| PMI制造 | 月度 | 50=荣枯线 | 统计局 |

**铁律**:
- 标题CPI和核心CPI分歧 → 以核心CPI为准
- PPI-PPIRM为负 → 中游制造业利润被挤压 → 不碰成本敏感型

### 维度 2: 信用（6个指标）

| 指标 | 含义 | 来源 |
|------|------|------|
| **Z-Credit** | 信用强度z-score | 用户月度PDF |
| Z-Monetary | 货币宽松强度 | 用户月度PDF |
| 剪刀差 | Z-Monetary - Z-Credit | 计算 |
| 社融增速 | 社会融资规模 | 央行/East Money |
| M1/M2 | 货币供应 | 央行 |
| 私人信用脉冲 | 私人部门信用变动 | 用户月度PDF |

### 维度 3: 实体经济（3个指标）
工业增加值、发电量、PMI

### 维度 4: 成本冲击（3个指标）
油价、进口价格、汇率

## 4. Step 2: 六象限判定

### 六种宏观状态

| 状态 | 仓位 | 历史占比 | 沪深300月均 | 特征 |
|------|------|----------|-------------|------|
| 宽信用扩张 | **80%** | 罕见 | +4.2% | 信用+增长+价格同涨 |
| 信用修复型再通胀 | **80%** | ~15% | +2.8% | 政策起效，信用转正 |
| 低通胀稳增长 | **80%** | ~8% | +2.1% | 金发女孩，股债双赢 |
| 紧信用放缓 | **55%** | 33.5% | +0.3% | 最常见，方向感最差 |
| **供给冲击型滞胀** | **50%** | 24.6% | -3.1% | 经济放缓但价格涨 ← 当前 |
| 通缩式下行 | **60%** | ~18% | +3.15%* | 需求塌缩，信用收缩 |

*通缩期月均回报反常为正（估值极低+政策预期），建议仓位从60%上调至70-75%。

### 供给冲击型滞胀判定条件

```
PPI加速 + PMI<51 + Z-Credit<0 + 核心CPI<1.5% + PPI-PPIRM<0
→ 五项全中 = 供给冲击型滞胀
```

| 条件 | 数值 | 阈值 | 判定 |
|------|------|------|------|
| PPI | +3.9%（4月+2.8%） | 加速 | ✓ |
| PMI | 50.0 | <51 | ✓ |
| Z-Credit | -0.74σ | <0 | ✓ |
| 核心CPI | +1.1% | <1.5% | ✓ |
| PPI-PPIRM | -1.9pp | <0 | ✓ |

**五项全中 → 供给冲击型滞胀，第5个月。**

## 5. Step 3: DC 滞回确认

L2 最核心的设计决策——**宁可滞后一个月，不要追着信号跑。**

```
CK 实时: 每月判断一次，状态随指标跳动
  → 28% 闪烁率（77/241个月与DC不同）
  → 每次假动作 = 一次调仓成本

DC 滞回: 退出条件满足后 → 再等1个月 → 确认后才切换
  → 0% 闪烁率
  → 每次切换都是真信号
```

### 回测结果（2006.02-2026.02, 241 个月）

| 指标 | DC 滞回 | CK 实时 | 买入持有 |
|------|---------|---------|----------|
| 累计收益 | +703.5% | — | +366.6% |
| 年化收益 | +10.93% | +9.99% | +7.97% |
| 夏普比率 | 0.62 | — | 0.29 |
| 最大回撤 | -43.6% | — | -70.8% |
| 月度胜率 | 58.5% | — | 56.0% |

### 五大核心发现

1. **"少亏"的复利价值 > "多赚"**：上行捕获率64%，下行捕获率49%，不对称优势
2. **DC 全面优于 CK**：年化多0.94pp，最大回撤少5pp
3. **纯 Alpha 年化+4.78%**：beta=0.63，不能被"低仓位"解释
4. **滞胀是核心贡献源**：仅此一状态累计贡献超+100pp
5. **通缩期仓位偏保守**：建议从60%上调至70-75%

## 7. Step 5: 不碰清单

**这是 L2 最有价值的输出。** 不碰清单是硬约束——不受帽子数字影响，始终生效。

### 当前不碰清单

```
供给冲击型滞胀 → 不碰成本敏感型中游制造业

逻辑: PPI-PPIRM = -1.9pp
  企业买入原料的涨幅比卖出产品快近2个百分点
  → 中游利润被挤压
  → 无法转嫁成本的企业 = 利润压缩

具体:
  PPI分项: 采掘+15.8%, 原材料+9.2% ← 成本端暴涨
  计算机通信电子设备 PPI: +2.1%      ← 售价端涨不动
  → 差值约-7~-13pp                   ← 利润空间剧烈收缩
```

### 不碰 vs 保留

| 类型 | 行业 | 原因 |
|------|------|------|
| **不碰** | 光伏/电池 | 成本端有色+化工，售价端补贴退坡/下游压价 |
| **不碰** | 基础化工 | 原油成本+产能过剩，两头受压 |
| **不碰** | 钢铁/水泥 | 铁矿石成本+地产需求弱 |
| **不碰** | 必选消费品 | 滞胀期不涨也不抗跌，现金才是防守 |
| 保留 | 半导体设备 | 高附加值，技术定价权，不受大宗商品影响 |
| 保留 | AI 芯片 | 国产替代逻辑独立于 PPI 周期 |
| 保留 | 军工电子 | 政府定价，不跟 PPI 走 |
| 保留 | 现金 | 滞胀期最好的防守（不是防守股） |

## 8. Step 6: L5 传导

### v1.2 输入结构：定量帽子 + 定性约束，AND 关系

```
[定量] L5_仓位帽子:
  日常: min(L0_WW×100%, L2_仓位上限)    // L1不介入
  极端: L1_硬帽子                        // L1=L4/L5时一票否决

[定性] L5_不碰约束:
  = L2_不碰清单 → L3翻译 → BK黑名单
  不受定量帽子数字影响，始终生效

AND 关系，不是 min() 关系。
40% 帽子下可以买满，但不能买不碰清单里的东西。
```

### 当前传导

```
L0: W&W=90.3 → ×0.4 → 40%
L1: SP500 L3 → 不介入
L2: 滞胀 → 50% + 不碰成本敏感型中游
L3: [空缺]

→ L5 定量帽子 = min(40%, 50%) = 40%
→ L5 定性约束 = 不碰成本敏感型中游制造业
```

### 对比旧公式

```
旧: L5 = min(L4, 70% × 50% × 0.4) = min(L4, 14%)
    → L1噪音+L2+L0三层叠加，过度收紧

新: L5定量 = min(L4, min(40%, 50%)) = min(L4, 40%)
    L5定性 = 不碰清单
    → L2独立输出，不参与定量乘法链
    → 40%帽子下钱只能放在L2允许的方向
```

## 9. L0/L2 冲突仲裁规则

> v1.2 新增。解决"情绪指标覆盖宏观判断"的逻辑不自洽。

### 规则

```
IF L0(Bullish/VeryBullish, ×1.0) AND L2(滞胀/通缩/紧信用):
  → L2_不碰清单优先于L0帽子数字
  → 定量可以宽松（帽子100%），定性不能放松
  → L5_定性约束 > L0_帽子数字
```

### 为什么

```
L0: 情绪温度计 — 测"市场冷热"，不测基本面
L2: 宏观象限 — 测"经济处什么状态"，有因果链

情绪可以骗人（2015年W&W=97但市场还涨了6周）
宏观不会（PPI-PPIRM=-1.9pp就是利润在缩小，不是情绪问题）
```

### 场景验证

```
场景A: L0=100%(Bullish) + L2=60%(通缩下行, 不碰周期股)
  → 定性: 不碰周期股  ← L2判断优先，虽然L0说"可以买"
  → 定量: 60% 帽子   ← min(100%, 60%)
  → 钱可以满，但不能碰周期股

场景B: L0=40%(Very Bearish) + L2=50%(滞胀)
  → 定性: 不碰成本敏感型中游  ← L2和L0方向一致(都谨慎)
  → 定量: 40% 帽子           ← min(40%, 50%)
  → 没有冲突，L0刚好更紧
```

## 10. 两种滞胀的区分

必须区分两种滞胀——操作完全不同：

| 维度 | 需求过热型 | 供给冲击型（当前） |
|------|-----------|-------------------|
| PPI 驱动 | 信用扩张/需求拉涨 | 产能治理/大宗商品/成本推动 |
| 信用方向 | 宽信用 | **紧信用** |
| 10Y 利率 | 跟随 PPI 上行 | **对 PPI 免疫** |
| 核心 CPI | 全面通胀 | **核心 CPI < 1.5%** |
| PPI-PPIRM | 正值或接近零 | **负值扩大** |
| A 股影响 | 杀估值全灭 | 结构性——砍成本敏感，留高附加值 |
| 防守策略 | 防守股 | **现金**（防守股不涨也不抗跌） |

### 判别公式

```
供给冲击型 = PPI加速 + Z-Credit<0 + 核心CPI<1.5% + PPI-PPIRM<0
```

在当前供给冲击型滞胀下——PPI 涨 ≠ 利率涨 ≠ 股市跌。**不因 PPI 加速砍半导体/AI 持仓。** 现金才是防守，不是防守股。

## 11. 6 个退出条件

滞胀结束需**至少 2 个条件同时满足** + DC 再观察 1 个月。

| # | 条件 | 当前值 | 阈值 | 状态 |
|---|------|--------|------|------|
| 1 | PPI 连续 2 月回落 | +3.9%，还在加速 | 回落 | ❌ |
| 2 | PMI > 51 连续 2 月 | 50.0 | >51 | ❌ |
| 3 | Z-Credit 向零收敛 | -0.74σ，创本轮新低 | →0 | ❌ |
| 4 | 私人信用脉冲转正 | -2.49% | >0 | ❌ |
| 5 | 核心 CPI > 1.5% | +1.1% | >1.5% | ❌ |
| 6 | PPI-PPIRM 差值转正 | -1.9pp | >0 | ❌ |

**全部六个不满足。短期不会退出滞胀。**

## 12. L3 职责与当前空缺

### L3 的定义

```
角色: L2宏观状态 → BK代码翻译器

输入: L2_不碰清单 ("不碰成本敏感型中游制造业")
输出: L3_不碰BK (具体BK代码列表)

示例:
  光伏(BKxxxx)    — 硅料成本端有色+化工，售价端补贴退坡
  电池(BKxxxx)    — 锂电材料，下游压价
  基础化工(BKxxxx) — 原油成本+产能过剩
  钢铁(BKxxxx)    — 铁矿石成本+地产需求弱
```

### 当前空缺

```
PPI-PPIRM 行业敏感度映射表 未建。
L2的不碰清单停留在概念层面，未翻译为BK代码。
无法进入 Stage 0-7 扫描流水线。

待建:
  1. 申万行业 → PPI分项映射
  2. 各行业成本结构中大宗商品占比
  3. 行业定价权评分（能否转嫁成本）
  4. 输出: 滞胀期BK黑名单
```

## 13. 数据源与已知限制

### 数据源

| 数据 | 来源 | 谁有 | 可靠性 |
|------|------|------|--------|
| CPI/PPI/PPIRM/PMI | 统计局 + Firecrawl | AI可爬 | 中（滞后1-2周） |
| Z-Credit/Z-Monetary | 用户月度PDF | 只有用户 | 不可替代 |
| 社融/M1/M2 | 央行 + East Money API | 部分可用 | 中 |
| 信用脉冲 | 用户月度PDF | 只有用户 | 不可替代 |

### 已知限制

1. **信用维度依赖用户 PDF**：这是 L2 的"VIX 问题"——50%的核心数据不在免费数据源
2. **月度频率**：L2 是中期工具，不是短期择时。信号有1-2个月滞后
3. **顶部识别强于底部**：做 risk-off 胜率高，做 risk-on 胜率低
4. **不含外部变量**：美债利率、美元、VIX 未纳入（这些是 L1 的职责）
5. **不预测政策**：政策是非统计事件
6. **L3 空缺**：不碰清单未翻译为 BK 代码
