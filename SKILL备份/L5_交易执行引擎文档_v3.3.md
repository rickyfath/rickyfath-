## 1. L5 是干什么的

**一句话：择股归 L4，执行归 L5。不回答"买什么"，只回答"怎么买、怎么卖、怎么管"。**

L5 是整个框架的最后一环。L4 给出战略仓位上限，L5 负责把它落到具体的买入价、止损位、加仓条件和卖出时机。

在框架中的位置：

```
L0  W&W 情绪       → ×0.4 刹车 → 40% 定量帽子
L1  SP500 风控     → 不介入 (极端时一票否决)
L2  六象限宏观      → 50% + 不碰清单
L3  产业周期        → T2已触发 + BK黑名单
L4  选股            → 13 Stage → 战略仓位上限
L5  交易执行        → 买/卖/管 ← 本层
```

---

## 2. 设计原则

```
1. L5 永远 ≤ L4 战略上限。只能向下调，不能向上加。

2. 定量帽子来自 L0-L2 传导链:
   L5_定量 = min(L4_战略, min(L0×100%, L2_上限))
   定性约束 = L2_不碰清单 → L3_BK黑名单 → Stage 2.0 自动过滤

3. CVaR/振幅缩放 = "防守因子"，不是"进攻乘数"。
   波动回归正常 → 实操仓位自动回到 L4 战略值。

4. 框架简化原则: 同一东西不量两次。
   新指标加入前强制检查: 它回答的问题是否已被现有指标回答？
```

## 3. Step 0: 前置检查

每次持仓诊断前执行。四项检查，数据复用上层，不重复拉取。

### [1] 六象限 ROE 领先指标

```
来源: L2 six-quadrant-model
不在此重复计算。
```

### [2] 残差动量持仓标签

```
来源: L4 择股时已计算
标签: 高beta假动量 / 高beta工具 / 独立逻辑 / 独立下行 / 中性跟随

用途: 标签不触发买卖，但当B条件触发时提高判断可信度:
  "高beta假动量" → B信号更可信，不要犹豫
  "独立逻辑"     → B信号可能只是回调，可以等确认
```

### [3] 市场风格标签 (v3.0)

```
沪深300 vs 中证500 相对强弱 → 大盘/小盘
创业板指 vs 上证50 相对强弱 → 成长/价值

背离规则:
  持仓=高beta成长小票 + 风格=价值大盘主导
  → 风格折价系数 ×0.7，提前收紧仓位，不等技术破位
```

### [4] 除权除息检测 (v3.0)

```
近30天单日涨跌 > 20%?
  20%-30%   → 等 5 个交易日
  >30%（高送转）→ 等 10 个交易日

MA失真期间用趋势定性替代MA数值判断。
区分: 除权缺口只影响MA数值，不影响趋势方向定性。
```

## 4. Step 1: 卖出双确认制 (A+B)

**铁律第一条，优先级最高。** 任何减仓/清仓必须 A+B 同时满足。两者缺一不可。

### A 条件（框架层 — v3.1 强弱分级）

不再是二元"否定/不否定"，而是三级：

```
强A（清仓级）:
  触发: z > +1.0（过热/透支）OR z 连续两季下行 > 0.15
  含义: 产业周期已结束 OR 景气确认拐头向下
  操作: 任何技术反弹都是卖点，不等B
  例外: 残差动量 A/B 级时先减半观察

弱A（减仓级）:
  触发: Δz < -0.10（单季急跌）OR PE分位 > 90%（市场抢跑）
  含义: 景气边际走弱但未到衰退 / 估值透支需回调
  操作: 降仓位至正常50%，保留底仓观察，等B确认后再全额执行

A条件不触发:
  L4"过热WARN" → "不加仓"，不是"卖出"
  L2"滞胀"     → 管控仓位上限，不是个股去留
```

### B 条件（技术层）

```
触发:
  收盘跌破MA20（连续两日）OR MA20拐头下行（5日斜率<0）

不触发:
  价格在MA20上方、MA20上行、MA多头排列完好

MA20破位三级判断:
  MA20没破（盘中未触及或盘中刺穿收回）→ 不算事件，持有
  假跌破（收盘刚破/幅度小/无量/无利空）→ 等一天确认
  真跌破（连续两日收MA20下方）→ 执行止损

核心: 收盘价是全天多空结算价，盘中刺穿不算有效跌破。
```

### B 条件量价验证 (v3.1)

```
缩量跌破（量 < 20日均量 × 0.8）
  → 无量假摔，减仓比例减半（原25%→12.5%，原50%→25%）

放量跌破（量 > 20日均量 × 1.5）
  → 资金出逃确认，按原比例执行

正常量能
  → 按原B分级规则执行
```

### B 条件内部细分: 弱B vs 强B

```
强B: 价破MA20 + MA20拐头下行(5日斜率<0)
  → 趋势已坏 → 全清
  → 给1个交易日缓冲: 次日反弹至MA20±2%遇阻→清仓；未反弹→当日清

弱B: 价破MA20 + MA20仍在上升(5日斜率>0)
  → 趋势未坏 → 按斜率强度分级处理
```

### 弱B斜率四档（新雷能116次历史回测, 2022.4-2026.6）

| MA20 5日斜率 | 历史次数 | 收复MA20率 | 5日收益均值 | 操作 |
|-------------|---------|-----------|-----------|------|
| **≥ 1.0** (强上升) | 15次 | **93%** | **+3.9%** | **不执行**，观察 |
| **0.5~1.0** (中上升) | 28次 | 79% | +2.0% | 减仓 25% |
| **0.1~0.5** (弱上升) | 49次 | 76% | -1.2% | 减仓 50% |
| **< 0.1** (极弱) | 24次 | 67% | -2.1% | 按强B全清 |

**回测关键发现**:
- MA20斜率是弱B事件后续表现的最强区分变量
- 强上升(≥1.0)时即使跌破MA20，5日后平均涨3.9%，减仓大概率是错的
- 极弱(<0.1)时MA20平均2.0天后就拐头，这不是"弱B"而是"准强B"

**跨股票换算**:
```
新雷能MA20约30-35元，斜率1.0 ≈ MA20的3%
百分比斜率 = (MA20_today - MA20_5d_ago) / MA20_5d_ago × 100
参考: 1.0≈3%, 0.5≈1.5%, 0.1≈0.3%
```

### B 条件大盘情绪修正器 (v3.3)

```
市场恐慌日判定（任一触发即判定）:
  条件1: WW逆向情绪指标 < 20（极度恐惧 — 全场在卖）
  条件2: CSI 300 单日跌幅 > 3%（系统性冲击）

恐慌日规则:
  弱B → 降级为观察，等下一日收盘再确认
    原理: 恐慌日全市场无差别抛售，MA20被动带破大概率是beta驱动
  强B → 执行不变
    原理: MA20在恐慌前已经拐头下行，趋势本身就坏了

正常日(WW>=20 且 CSI 300跌幅<=3%) → B条件按原规则正常执行
```

### MACD 背离辅助 (v3.3)

```
顶背离（价创新高 + MACD DIF走低）:
  B条件破位时 → 信号更可信，不降级处理
  原理: 价格在涨但动量在衰竭，MA20破位确认了衰竭

底背离（价创新低 + MACD DIF走高）:
  弱B → 更有底气等反弹确认，可延迟一级执行（减仓50%→减仓25%）
  强B → 不影响（MA20拐头下行信号优先级高于背离）
  原理: 价格在跌但动量在积累，破位可能是最后一跌
```

### 振幅辅助判断

```
在评估"跌破幅度是否够大"时，必须参考近期日内振幅:
  - 日常振幅 5-8%: MA20跌破1%是有意义的信号
  - 日常振幅 10-15%: MA20跌破1-3%可能只是噪音
  - 高振幅+MA20仍在上升 = 更可能是冲高回踩，不是趋势反转
  - 高振幅+MA20已走平/下行 = 趋势松动的警告
```

### 持仓性质微调

```
弱B时先按斜率分级确定操作，持仓性质作为辅助参考:
  战略持有: 在斜率分级基础上可保守一档（如0.5~1.0→可不减）
  周期反转: 按斜率分级严格执行，不微调（拐点博弈容错空间小）
  Tier 2: 强B全砍，弱B按斜率分级执行

强B(MA20已拐头下行) → 不论持仓性质，全清。
```

## 5. Step 2: Tier 2 进攻仓位

强趋势时叠加进攻层。不是独立额度，是从基础仓位到 L2 总上限之间的差额。

```
Tier 2 可用 = L2 总上限 - 当前基础仓位
例: L2滞胀50% - 基础40% = +10%
```

### 条件清单（六条全满才执行）

```
[0] 所有持仓底仓浮盈 > 10%（v3.2）
    任一只 < 10% → Tier 2 不触发
    只在盈利头寸上加进攻，禁止亏损时摊平成本

[1] 所有持仓收盘价 > MA20

[2] 所有持仓 MA20 5日斜率 > 0

[3] 上证 MA60 10日斜率 > 0

[4] ≥ 2 只持仓的 BK 板块指数 MA20 5日斜率 > 0
    个股强 + 板块弱 = 逆水行舟

[5] 20 日均振幅 < 5.5%（CVaR 环境正常）

0-5全满 → Tier 2全额 (+10-15%)
0-4满但5不满 → 减半 (+5-8%)
0不满或任一1-4不满 → 不触发
```

### 退出条件

```
任一持仓收盘跌破 MA20 → 砍整个 Tier 2 层
回到基础仓位，不是只砍跌破的那只。
假跌破等一天确认，同双确认制 B 条件规则。
```

### 标的筛选漏斗

```
1. 自选池全量技术面扫描（MA20上方 + MA20向上 + 非过热）

2. L4产业周期交叉验证（剔除过热/顶部初现/内卷陷阱行业）

3. BK板块MA20斜率验证
   候选标的所属BK板块MA20 5日斜率 > 0?
     否 → 排除。个股强+板块弱=逆水行舟
     是 → 继续

4. 距MA20 < 15% + 20日位置 < 95%（不在加速段）

5. 量能筛选（量比 > 0.8，缩量阴跌的排除）

6. 60日涨幅分位 20-60%（中间最优 — A股动量倒U形）
   >80% → 不买（高位追涨在A股是最差策略）
   <20% → 需基本面确认

7. 质量分档额度:
   L4评级 A  → Tier 2 上限 15%
   L4评级 B  → Tier 2 上限 10%
   L4评级 B- → Tier 2 上限 5%
   未评级/C  → 不进入 Tier 2
```

### 60日涨幅分位规则

```
来源: A股动量策略检验报告 (2014-2026, 149月, 5766只股票)
核心发现: A股五组收益呈倒U形 — 中间组表现最好

分位组    月均收益    含义
Q1(最低)   +0.65%     输家
Q2         +0.98%
Q3(中间)   +1.07%     ← 历史最优区间
Q4         +1.02%
Q5(最高)   +0.85%     赢家跑输市场均值

原因: A股以散户主导、高换手，过度反应更易反转而非惯性。
```

## 6. Step 3: 分批建仓

**核心原则**: 永不加仓亏钱头寸。A被止损→等下一次MA20重新站上信号。假突破2日内可重探A但不得追补B/C。A和B之间至少隔3个交易日。

### 大黑马（高质量成长，上限 8-15%，分三批）

```
A 试探仓 40%计划仓位
  触发: MA20走平拐头向上 + 连续2日收盘站上MA20 + 量>20日均量
  止损: MA20
  逻辑: 多重确认过滤假突破

B 确认仓 30%计划仓位
  触发(任一):
    (a) 回踩MA20 ±3%区间止跌放量反弹
    (b) 自A入场后涨超5%且站稳MA20满5日
  止损: 保本价（A+B均价）

C 加码仓 30%计划仓位
  触发: MA10>MA20>MA60全多头排列 + 创20日新高
  止损: MA10(C部分) + MA20(A+B部分)
```

### 周期反转（底部拐点，上限 5%，分两批）

```
5%太小拆三批没意义:

A 试探仓 60%计划仓位
  触发: MA20站上（收盘确认）+ 量>20日均量1.5倍 + 催化剂明确
  止损: MA20

B 确认仓 40%计划仓位
  触发: MA20站稳满5个交易日 + MA20拐头向上
  止损: 保本价(B部分) + MA20(A部分)
```

## 7. Step 4: 减仓后买回三部曲

减半后（如20%→10%）买回目标仓位，三个条件缺一不可：

```
1. 放量站上MA20
   收盘价 > MA20 + 量能放大（不是缩量站上，过滤假突破）

2. MA20方向拐头向上
   MA20不再下行，开始走平或上升（5日斜率>0）
   站上往下走的MA20 = 假突破高发区，不能买

3. 缩量回踩MA20不破
   站上后出现自然回调，缩量回踩MA20获得支撑
   过滤"一日游"式假站上
```

### 分批买回节奏

| 步骤 | 时机 | 买回幅度 | 累计 |
|------|------|---------|------|
| 第一步 | 放量站上MA20 + MA20走平 | +5% | 15% |
| 第二步 | 缩量回踩MA20不破 | +5% | 20% |

如果买回后又跌破MA20：再砍一半。每次跌破MA20是独立事件，每次都执行。可以被洗三次五次，只要每次只亏MA20到买回点之间的差价。

## 8. Step 5: 追踪止损 (v3.1 梯度收紧)

触发条件: 浮盈 ≥ +20%。

### 梯度收紧

```
浮盈 20-50%:
  止损线 = max(MA20, 建仓以来最高收盘价 × (1 - 1.5 × ATR%))

浮盈 50-100%:
  止损线 = max(MA20, 建仓以来最高收盘价 × (1 - 1.0 × ATR%))
  → 收紧至 1×ATR

浮盈 > 100%:
  止损线 = max(MA20, 建仓以来最高收盘价 × (1 - 0.8 × ATR%))
  → 最紧档
```

| 变量 | 更新频率 | 说明 |
|------|---------|------|
| 最高收盘价 | 每日 | 创新高则刷新 |
| MA20 | 每日 | 滚动计算 |
| ATR(20日) | 弹性更新 | 默认周五；连续两日日振幅>5%→日更 |

**止损线只升不降。**

### 加速冲顶主动止盈

```
10个交易日内涨幅 > 30% → 情绪冲顶信号
  → 主动减仓 20-30%，不等止损线触发
  → 原理: 短期急涨 = 最后冲刺
  → 剩余仓位继续按梯度止损线管理
```

### 出场两层

```
触发追踪止损(收盘 ≤ 止损线) → 减半仓位（锁利润）
        ↓
    剩余仓位回到MA20止损
        ↓
  收盘 ≤ MA20 → 全清
```

## 9. Step 6: CVaR 下行风险缩放

**理论基础**: Kim & Kim (2021)。CVaR（最坏5%平均损失）在90年全球数据中全面优于波动率缩放。注意CVaR缩放因更高平均仓位，绝对MDD反而更大——优势是"回报增幅超过风险增幅"。

### 振幅缩放因子

```
仓位上限 = L2宏观上限 × L1映射系数 × 振幅缩放因子

振幅缩放因子 = 4% / max(4%, 20日均振幅%)

  正常市(均振幅 3-4%):   ×1.0
  颠簸市(均振幅 5-7%):   ×0.6-0.8
  剧烈市(均振幅 8-10%):  ×0.4-0.5
  极端市(均振幅 > 12%):  ×0.33

原理: L2滞胀50%上限在"平稳波动"和"剧烈波动"中，实际风险完全不同。
      CVaR高→仓位自动缩；CVaR回归→仓位自动恢复。
```

### 个股尾部风险分档

```
基于20日日内振幅均值:

正常:
  均振幅 < 5.5%，高振幅天数 < 5/20
  → ×1.0, 大黑马上限15%, 周期反转5%

高波动:
  均振幅 > 5.5%，或高振幅天数 > 5/20，或亏损股
  → ×0.5, 大黑马→7.5%, 周期反转→2.5%
```

**阈值来自A股实际分布标定**（20只股票, 420个观测）: 中位数3.4%, 90%ile 6.1%, 95%ile 7.0%。

### ROE 锚

```
PE高(>70%ile) + ROE高(>70%ile) → 贵得有道理
  → CVaR系数不额外打折

PE高(>70%ile) + ROE低(<30%ile) → 贵得没道理
  → CVaR系数额外降0.5档

PE低(<30%ile) + ROE低 → 便宜有原因
  → 不因便宜而加仓，可能是价值陷阱

PE低(<30%ile) + ROE高 → 最理想组合
  → 可能是被错误定价
```

## 10. Step 7: 现金纪律

框架的仓位上限是**上限**，不是**目标**。

```
滞胀期/熊市 + 可选标的减少 + 最优方向已配满
  → 剩余仓位 = 现金
  → 不是"踏空"，是"纪律"

操作含义:
  - L2滞胀50%上限 ≠ 必须满50%
  - "不知道买什么"不是问题需要解决——是框架在告诉你当前环境可投标的稀缺
  - 框架的否定判断（不碰什么）比肯定判断更有价值
  - 70%现金在滞胀期不是"踏空"，是"纪律"

铁律: 持仓的对手方不是"空仓"，是"现金+更好的机会"。
      没有更好的机会，现金就是最优持仓。
```

## 11. Step 8: 技术计算铁律

### MA20 切片 Bug（严重 — 2026.7.2 发现）

```
错误: list[-20:0] 在 Python 中返回空列表！
  closes[-20:0] = []  → MA20 = 0.00 → 斜率完全错误

真实后果 (2026.7.2菲利华):
  错误: MA20序列 ...→ 0.00 → 斜率-1.10% → 设"全清"
  正确: MA20序列 ...→ 126.36 → 斜率+0.434%
  正确决策: 弱B → 减仓50%，不是全清
  偏差: 全清 vs 减仓50%，差了一倍仓位

防范:
  1. 任何 MA20 计算脚本，先打印完整序列验证无 0.00
  2. 不使用 list[start:0] 形式切片
  3. 跨天比较时确认同一套代码
  4. 斜率符号与直观趋势矛盾时立即怀疑 bug
```

```
  [ ] MA20 5日斜率与10日斜率符号一致（不一致要解释）
  [ ] 昨日 vs 今日斜率方向可衔接
```

### MA20 计算正确写法

```python
closes = [...]  # 从API拉取的收盘价序列

ma20_values = []

for offset in range(-10, 0):
    if offset == -1:
        ma = sum(closes[-20:]) / 20      # 正确：[-20:] 取最后20个
    else:
```
