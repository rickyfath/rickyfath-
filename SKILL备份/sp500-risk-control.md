## 核心分析工作流：外部信号 -> 特征映射

用户经常观察到的市场信号不在模型直接监控范围内。需要做二层映射。

### 信号映射表

| 用户观察信号 | 影响特征 | 方向 | 滞后 | 盲区风险 |
|-------------|---------|------|------|---------|
| 10Y收益率涨 | 期限利差反转_z | 看2Y是否同步：若10Y涨更快->利差扩大->z减小(有利)；若2Y涨更快->利差收窄->z增大(危险) | 日度 | 不区分长端/短端驱动力 |
| 油价涨 | VIX_z(间接), HY变化_z(间接) | 通胀预期->加息预期->VIX升+信用利差扩大 | 数周 | **模型无直接油价指标** |
| 纳指缩量暴涨 | 标普趋势_z, 均线斜率_z | 价格涨->z减小(虚假改善) | 周度 | **模型完全盲区量能** |
| 美联储鹰派发言 | VIX_z, HY变化_z | z增大 | 即时 | 前置信号，VIX先反应 |
| 信用事件(违约) | HY变化_z | z增大 | 数日 | 模型有直接覆盖 |
| 失业率跳升 | Sahm_z | z增大->可能触发否决权 | 月度 | 否决权专用，频率低 |
| S&P 500涨但EPS未跟上 | SP500趋势_z, MA斜率_z | 价格涨->特征虚假改善(骗降级) | 季度(EPS滞后) | **模型完全盲区盈利质量** |

### 盈利驱动 vs 估值驱动 月频检查（2026.6.10新增,来源GS US Equity Views）

GS 2026.5.26报告核心发现：过去两年S&P 500涨40%，P/E倍数零贡献(21x→21x)，100%由盈利增长解释。这个关系是判断L1信号可靠性的关键补充：

```
月频计算:
  过去12个月S&P 500涨幅 = (SP500_today - SP500_12m_ago) / SP500_12m_ago
  过去12个月Forward EPS涨幅 = (FwdEPS_today - FwdEPS_12m_ago) / FwdEPS_12m_ago

  差值 = 价格涨幅 - EPS涨幅
  
  > +5pp: 估值驱动上涨 -> L1的SP500趋势_z和MA_z改善可能是虚假的 -> 陷阱4触发
  0~+5pp: 健康上涨 -> 盈利验证价格, L1信号可靠
  <0: 盈利驱动但价格未跟上 -> 反向陷阱, 可能低估了市场
```

**陷阱4：估值驱动上涨 -> 模型虚假改善（2026.6.10新增）**

当S&P 500涨但EPS没跟上：
- SP500_z和MA_z改善（权重35%）-> Score自动下降 -> 模型可能降级
- 但涨幅没有盈利支撑 -> 一旦EPS预期下调，价格回调会很快
- 此时L1的降级信号不应执行加仓，保持原仓位

**检查方法**：当L1状态改善（从地狱->噩梦->困难方向移动）时，计算盈利vs估值差值。差值>5pp时，降级信号打7折处理（如从50%上限只提到60%，不是70%）。

**数据源**：S&P 500 Forward 12m EPS可从FactSet或Bloomberg获取，无免费API。季度替代方案：每季度财报季后手动记录共识EPS预测。GS报告(每季度发布)本身就是最佳数据源。

### 陷阱场景（必须检查）

**陷阱1：缩量暴涨 -> 模型虚假降级（最危险）**

这是模型最容易被骗的时候：
- SP500涨 -> SP500_z和MA_z两个特征（共35%权重）同时改善
- 综合评分快速下降 -> 模型可能从地狱/噩梦自动降级到困难/普通
- 仓位上限打开（35%->70-85%），但缩量意味着涨势不健康
- 一旦外部冲击（油价、利率），VIX反抽触发否决权 -> 仓位已高位 -> 回撤放大

**铁律：模型降级时，检查量能。缩量降级不执行加仓。**

**陷阱2：油价 -> 模型滞后**

油价涨通过通胀预期->利率->VIX的链条传导，有2-4周滞后。模型在这期间可能显示"一切正常"，但VIX_z正在积累爆发燃料。当VIX_z从<1跳到>2通常只需1-2周。

**陷阱3：利差解读歧义**

10Y涨有两种场景：
- A) 增长预期改善（利空债市，利好股市）-> 利差扩大 -> 风险降低
- B) 通胀溢价上升（滞胀前兆）-> 2Y可能涨更快 -> 利差收窄 -> 风险升高

区分方法：同时看油价和VIX。若油价+VIX也在涨 -> 场景B（滞胀），危险。

## SP500模型对A股的适用性（铁律）

**SP500风控模型的设计目标市场是美国，对A股不能机械套用。**

### 适用场景（高相关性）
- VIX飙升到30+ → 全球恐慌 → A股外资撤离 → 按L1减仓
- HYG暴跌 → 信用危机 → A股高beta板块跟跌 → 按L1减仓
- 模型在"炼狱"(L5)→15%仓位 → 全球危机中 → 保守是对的

### 不适用场景（低相关性）
- 模型在"地狱/噩梦"但SP500在温和上涨 → 不要因L1压缩A股仓位
- A股在交易独立逻辑（军工、电力投资、国产替代）→ L2六象限比L1更重要
- 美股涨A股跌（中国自身风险）或美股跌A股涨（政策对冲）→ 方向相反时L1无效
- 量能不能确认 → 模型盲区（SP500模型不含量能指标）→ L1信号可靠度降低

### 正确用法
L1输出的是"全球风险温度"，不是"A股仓位指令"。最终仓位上限取min(L1映射, L2映射)，但当L1和L2方向不一致时，**A股仓位优先跟L2六象限，L1仅在全球极端风险时行使否决权。**

## 用户框架定位 (v4.1 修正 2026.7.5)

L1风控只输出否决权，不参与日常仓位决策。三层分工：
- L0(情绪温度计): A股本土情绪刹车 → 压缩系数 ×0.4/0.6/1.0
- L1(SP500风控): 全球危机否决权 → 仅在L4/L5时硬帽子介入
- L2(宏观象限): 大类资产偏好 → 给方向
- L3(行业周期): 行业选择 → 选赛道

v4.1核心修正：L1从日常乘法链退出。SP500数据判断A股日常仓位没有因果依据。
日常: L5 = min(L4, L0_WW × 100%)  — L1不参与
极端: L5 = L1_硬帽子(35%或15%)    — L1一票否决，L0不叠加

## 实时诊断工作流（6步）

当用户询问当前市场风险状态、仓位建议、或观察到特定市场信号需要框架验证时，执行此工作流。

核心逻辑：**模型给出历史状态（滞后1-5周）+ 实时数据推断特征方向变化 = 当前风险判断。**

### 步骤1：读取模型最新状态

```python

# 市场状态总览 最后15行 -> 综合评分、SP500点位、回撤
```

**步骤1a：检查模型时效性（强制）**

读取后立即检查最后一行数据的日期。若距当前超过3周：
- 标注"[WARN] 模型滞后X周，以下为估计区间非精确值"
- 模型Score和Status不作为精确仓位指令
- 结合步骤2-4的实时数据做方向推断
- 输出仓位建议时用范围（如"40-50%"）而非单点

### 步骤2：拉取实时市场数据

运行 `scripts/compute_sp500_score_v3.py`（无Yahoo依赖，中国IP可用）。

- 详见 `references/global-data-sources.md` 和 `references/ticker-mappings.md`

### 步骤3：纳斯达克量价分析

不只报价格涨跌，必须拆解量价关系：

| 模式 | 信号 | 含义 |
|------|------|------|
| 放量涨 | 健康 | 资金跟进 |
| 放量跌 | 不健康 | 主动卖出 |
| 放量滞涨 | [WARN] 危险 | 机构出货，量推不动价 |
| 缩量涨 | [WARN] 危险 | 无量空涨，没有新资金 |
| 缩量跌 | 中性 | 自然回落 |

关注"放量滞涨后缩量拉升"模式 — 最经典的顶部出货结构。

### 步骤4：各特征方向判断

对照模型最新z-score和实时数据变化，逐个判断5特征方向：

| 特征 | 权重 | 数据源 | 判断依据 |
|------|------|--------|----------|
| VIX_z | 25% | VIX实时 | VIX升降方向 |
| HY变化_z | 25% | HYG/LQD走势 | HYG下跌=利差扩大=风险升 |
| 期限利差反转_z | 15% | 10Y+2Y收益率 | 利差扩大=风险降，收窄=风险升 |
| SP500趋势_z | 15% | SP500价格 | 涨=改善，跌=恶化 |
| MA斜率_z | 20% | SP500 MA40 | 涨=改善，跌=恶化 |

注意：SP500价格涨会让特征4和5"改善"（权重35%），但如果涨法不健康（缩量），这个改善是虚假的。

### 步骤5：综合判断

- 估算评分方向（各特征权重加权）
- 判断模型可能的状态变化（升级/降级/维持）
- 检查否决权风险（VIX_z>2? HY_z>2? Sahm>2?）
- **关键检查：L2（价格趋势）和L3（量能+信用）是否一致。打架时信L3。**

### 步骤6：输出诊断报告

格式与上文"回答用户的输出结构"一致，分层输出：
1. 数据确认表（模型最新 vs 实时）
2. 量价拆解（纳斯达克日线）
3. 特征方向汇总
4. 核心矛盾（如有）
5. 结论 + 仓位建议 + 盯盘扳机

| A股财务 | East Money datacenter | akshare stock_financial_abstract_ths | 季度/年度数据 |

**SP500修正系数校准规则**：每次用户提供可靠SP500值时（如其自建数据管道），重新计算 `修正系数 = 真实SP500 / Sina int_sp500`，用于后续估算。该系数会随Sina API行为变化而漂移，不定期校准。

**模型数据滞后（最高优先级检查）**：每次读取模型Excel后，首先确认最后一行数据的日期。模型周度更新，如果最后日期距当前超过3周，模型的Score和Status已不可直接使用。必须：
- 标注"模型滞后X周"
- 用实时数据（Sina SP500/HYG/原油）推断特征方向变化
- 给出估计区间而非精确值（如"估计在噩梦到地狱边界"而非"Score=0.34"）
- 不要直接引用滞后Score做仓位指令

**信用-股市裂口**：HYG/LQD持续下跌而股市上涨 = 信用市场和股市方向矛盾。历史上裂口总是收敛，收敛方向通常是股市向信用市场靠拢（下跌）。

**2Y收益率数据缺失**：Yahoo Finance无直接2Y收益率ticker。替代方案：用5Y(^FVX)和13W(^IRX)推断，或搜索"US 2Y yield"。不要用2Y期货价格(ZT=F)代替。

**Yahoo Finance geo-block**：从中国IP返回403或HTML验证页。yfinance库同样被限流。不要反复重试 — 直接切换到Sina备用方案（`hq.sinajs.cn`），VIX/10Y不可获取时回退到模型Excel快照并注明。

### 诊断陷阱8: VIX/HY陈旧时Score可偏差两个风险级别（2026.6.14确认）

当VIX和HY两个特征（合计50%权重）均沿用陈旧Excel值时，计算出的Score可能严重失真。

本session实测：
- agent计算: Score=+0.275, Pct=70.3%, L4地狱 (VIXz=+0.844沿用4/10, HYz=-0.001因周线API失败)
- 用户自建管道(同日): Score=-0.233, Pct=53.2%, L2困难 (VIXz和HYz已更新)
- 偏差: Score差+0.508, 跨两个风险级别 (地狱→困难)

根因：VIXz从4月的+0.84实际已降至~+0.18 (6/6)甚至更低 (6/12)，HYz从+0.64降至约-1.10。这两个特征的累积改善足以将Score从地狱拉到困难。仅靠SPz/MAz/Sprz三个可获取特征（50%权重）方向推断，Score偏差可达0.3-0.5。

铁律：
- 当VIXz或HYz任一沿用超过3周的陈旧值时，**不输出精确Score和百分位**
- 替代做法：用SPz/MAz/Sprz做方向确认，输出定性判断 + 仓位范围
- 如果用户有自己的数据管道（如其自建跟踪表），**优先采信用户数据**，不拿自己计算的不准确值去"修正"
### 诊断陷阱7: VIX无实时源 + 方向推断不可替代精确计算

**VIX从中国IP已无可用免费数据源**（2026.6.10确认, Yahoo/CBOE/Finviz/MarketWatch全403），`compute_sp500_score.py` v3已改用Excel VIXz沿用+标注机制。Sina SP500需*1.111修正（2026.6.6校准: Yahoo7384/Sina6644）。

当模型Excel滞后超过3周时，不能仅靠实时数据方向推断Score。本session实测：AI初步估计Score=0.45-0.55（地狱/噩梦边界），但精确计算得Score=-0.381（困难L2），相差两个级别。原因：低估了信用利差改善（HYz从+0.64变-1.10）和期限利差转正（10Y-2Y从倒挂变+0.38%）的综合效应。铁律：模型滞后时先用方向推断给粗略区间，然后尽可能用`compute_sp500_score.py`跑精确值——尤其当多个特征方向不一致时，肉眼加权非常容易出错。HY OAS 13周变化通过HYG价格变化近似（系数-2.5x），非精确值。
